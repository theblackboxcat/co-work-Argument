# 非定向伴写系统 · 使用文档

> **本 README 描述的是 v2.0 那一层**（非定向：只举证、绝不生成正文、A/B/C 判层）。
> **v3.1（执行文档_hy4进化版v3）已在 `v3/` 下建成**，它把目标改成
> "让作者更想写、写得更顺、写完更确定这是自己的东西"，
> 引入 P/M/S 三种文本模式、D1–D10 禁令矩阵、体验层埋点与 hy4 进化循环。
> **v3.1 是文明化重构**：反馈从"给方案"改为"朋友式开放式讨论"，
> 新增 C1–C10 文明条款（不指你、承认不确定、不评价、只问真问题、给退路、
> 不逐句批改、不用判词、不替作者定调、不中英混杂、不问写作状态）。
> 两层共存是为了做**冷启动对照**：同一批段落分别跑两套策略，由作者反馈决定往哪走。
> → 见文末「七·v3」。


面向**未完成文本**的人机伴写原型：一个网页 + 一个文档读取接口 + 一套给模型的工作流约束。

核心立场：**只举证，不定向；只核已写下的，不猜将要写的。**
伴写者会主动开口，但主动性只作用于**时机**，不作用于**方向**。

> 本系统**不内嵌任何作品**。它的唯一依据是作者现场载入的文档。
> 没有载入文档时，它一律声明沉默，绝不用任何预置文本冒充证据。

## 1. 三分钟跑起来

```bash
cd %DSH_ROOT%\lir\文献\dsh-伴写
python server.py
```

浏览器打开 **http://127.0.0.1:8790**（若被占用改 `server.py` 顶部的 `PORT`）。

1. 点右上角 **「打开文件」**，把你的稿子载进来（`.txt` / `.md` / `.docx`）
   —— **这一步是关键**：载入后全文会进写作区，伴写从此"看得到原文"。
2. 在写作区继续写，或把光标放到某一段上。
3. **停止输入 8 秒**，右侧伴写面板给出回应；也可点「立即伴写」跳过等待。

## 2. 它识别三层，每层给不同的东西

模型**自己判定**作者当下在哪一层，然后走不同的分支。层标记显示在卡片左上角。

| 层 | 判据（第一个答"是"的即用） | 它做什么 | 它绝不做 |
|---|---|---|---|
| **A 思路性** | 这一段有对动机/意义/性质的**判断**，且在文档里没有着落 | **回映**：把你自己的两个词并置还给你 | 给主题命名、升华、评价 |
| **B 结构性** | 这一段的事物在文档**别处出现过**，或作者在搁置/跳接/调序 | **指位置**：说出跨段落的呼应/重复/断层 | 提改法、评节奏 |
| **C 情节性** | 这一段让状态**发生改变**，且前面已写过相关因果 | **核自洽**：核对已写下的因果是否对得上 | 预测"接下来" ← **第一大忌** |
| **⊘ 沉默** | 判不出，或文档里没有可依据的东西 | **主动声明**沉默（⊘₀–⊘₃） | 硬凑一句 |

**为什么 Q_A 排在最前面**：A 的信号最独特而风险最高，
且最容易被误判成 C（"她才知道"看起来像情节推进，其实是作者在下判断）。

**实测样例**（载入一份与本项目无关的草稿后）：

| 停下的段落 | 层 | 实际输出 |
|---|---|---|
| 「后来她才知道，母亲只是想一个人走走。」 | A | 你在这一段里把"母亲只是想一个人走走"和前文"买酱油却空手回来"并置，中间没有过渡。 |
| 「她说伞坏了。他说修修就行。然后就没有下文了。」 | B | 「伞」在第 3 段出现过一次，第 7 段是第二次出现。中间没有别的地方再提过伞。第 7 段末尾的「没有下文」是明确的搁置。 |
| 「他来得比信上说的晚了两天。进门的时候鞋上全是泥。」 | C | 雨下了三天（第 2 段），他来得晚了两天、鞋上全是泥（第 6 段），这两处时间与天气的因果在文档里没有其他印证。我不判断这些是忘了还是有意的。 |
| 「火星殖民地的第三座穹顶在沙尘暴里亮着灯。」 | ⊘ | 这一段我找不到可依据的东西，所以我不说话。 |

## 3. 接口

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/doc` | POST | 载入文档。body：`{name, text}` 或 `{name, b64}`（docx 传 base64）。返回 `{meta, text}` |
| `/api/doc` | GET | 取回当前文档（前端刷新后恢复原文） |
| `/api/cowrite` | POST | 伴写。body：`{text, prev, section, selection, attention, anchor}`。`selection` 为 `{start,end,text}`，窗口化时 start/end 是全文坐标 |
| `/api/workflow` | GET | 返回 `WORKFLOW.md` 全文（给 agent 读） |
| `/api/status` | GET | 在线状态 / 当前模型 |
| `/api/fullread` | GET/POST | 全文阅读进度与全书记忆；POST 强制重新逐片阅读 |

`cards[].layer` ∈ `A` / `B` / `C` / `⊘`，前端据此渲染彩色徽章与左边框。

## 4. 接模型

`config.json`（**已由你配好，不要动**）：

```json
{ "base_url": "...", "api_key": "...", "model": "...", "api": "anthropic-messages" }
```

两个可调项（都可不写，有默认值）：

| 键 | 默认 | 说明 |
|---|---|---|
| `thinking` | `disabled` | **默认关闭思考**。实测开启后延迟 4s→35s，且思考块会吃满 `max_tokens` 导致正文为空 |
| `max_tokens` | `2048` | 思考开启时务必调大 |
| `input_chars` | 按 provider | 单次送入模型的字符预算；超过会分片/检索，不再硬截前 N 字。`dots3` 默认 12000 |
| `continuation_rounds` | 按 provider | 输出触发 `max_tokens` 后自动续写的最大轮数；`dots3` 默认 4 |
| `output_chunk_tokens` | 按 provider | 单轮输出 token 上限；`dots3` 默认 4096，超出部分由自动续写补齐 |

模型失败会自动降级到离线规则引擎，界面标 `offline(fallback)`。长材料动作会按自然段分片后完整处理；长对话超出预算时改用“相关片段 + 首中尾样本”的检索上下文，并明确告知模型不是全文。

## 8. 已知限制（照实说）

1. **"非定向"尚未被度量。** 系统按约束实现，但"它是否真的不歪曲定向"需要人的对照实验，本原型不做这个测量。**接了真模型 ≠ 证明了它不定向。**
2. **相关片段检索是二元切分 + 受限单字**，不做分词。长文档上可能漏掉语义相关但字面不重叠的呼应。
3. **未实现流式输出**，真实模型模式下要等完整响应（关闭思考后约 1–2 秒）。
4. **段落号基于空行切分**，没有用 `.docx` 的原始段落结构。
5. **文档只存在内存里**，重启服务即丢失，需要重新载入。

**目标变了**：不是"帮作者写得更好"，是"让作者更想写、写得更顺、写完更确定这是自己的东西"。

### 怎么跑

```bash
cd v3
python extract_lir.py --list                # 看有哪些章
python extract_lir.py --first 7             # 抽原文前七大章进 corpus/
python scan.py                              # 全量过分类器，看真实分布（不调模型）
python runner.py --per-file 3 --judge       # 每章等距抽 3 段做对照（约 5 分钟）
python runner.py --limit 20 --judge         # 或按顺序取前 20 段
python runner.py --arm v3 --per-file 1 --civility   # 只跑 v3 并判文明度（指点感）
python runner.py --corpus corpus_非P --limit 12 --civility  # 只跑 M 模式样本
python runner.py --dry                      # 不调模型，只检查流程
```

产出都在 `v3/logs/`：`samples.jsonl`（埋点）、`反馈表.md`（**给作者标**）、
`对照报告.md`、`模式分布.md`。

### v3.1 文明化重构（2026-09-15，作者指出"不要让人有在接受指点的感觉"之后）

**诊断**：v3.0 的反馈是"分析很强、姿态很硬"——给方向、列清单、下判断。
按 SIGIR'24 的 Civility 分类（arXiv 2404.12670），这是 **Opponent 型**：
智能与适应性都高，文明度低，于是显得侵扰、不尊重。

**改了什么**

| | v3.0 | v3.1 |
|---|---|---|
| 输出形态 | 方向一／方向二／方向三 | 接住 + 我的读法 + 我的好奇 |
| 主语 | 「你这里…」「你可以…」 | 「我读到…」「我在想…」 |
| 确定性 | 说定论 | 留「也可能是我读错了」 |
| 评价 | 隐含褒贬 | 描述，不打分 |
| D8 | 强制三选一 | **反转为严禁清单** |
| 模式标记 | 输出 `[P]` | 不再输出（只用于内部校正读法） |
| 长度 | 93–374 字 | 上限 180 字（P） |

**新增**：C1–C10 文明条款。模型判 `judge.py:judge_civility()`（temp=0.2）
＋ 正则判 `metrics.py:civility_hits()`，两层互相兜底。

**通信姿态的范本**：项目内《云酒与猫猫_深度对话_出版整理版》——
两个人聊文本时说的是「我在想／我好奇／我卡住了」，不是「你应该」。

**实测（《爱别离》前七章各等距 2 段，n=14）**

| 指标 | 基线 v2（n=7） | v3.1（n=14） |
|---|---|---|
| 文明度违规·模型判 | 17 条（7 条样本） | **2 条**（均为 C6 引原文偏多） |
| 主要违规项 | C1 指你、C2 不确定、C8 替作者定调、整体指点感 | 仅 C6 |
| 输出字数 | 32–146 | 100–215（上限 180） |

脚本侧另报 C6（7/14）、C1+C7+C5 各 1 处。
**短输出里引原文 3 处是否真的构成指点感，自动判定给不了答案——这一条留给作者标注。**

**待作者确认，未再自行调整。**

### v3.1a 接住重构（作者指出「停了一下／震了一下太生硬」之后）

这个版本指出的问题是**结构性的，不是措辞问题**：v3.1 要求先「接住」，
而我给的示范句是「我读到 X 时停了一下」——**它就变成了每条输出的开头**。
写进提示词的正例也会变成模板（v3.0 曾经用反面例句踩过同一个坑）。

拿真实语料一量就露馅了（作者提供的两人聊天记录，**23660 条**）：

| 现象 | 数据 |
|---|---|
| 「我读到」出现次数 | **1 次**（0.004%） |
| 承接句中位数长度 | **16 字** |
| ≤15 字的话轮占比 | 71.2% |

改法：

- **禁用「我读到／我看到／我注意到 X……」整个句式**（不只是禁止当开头）；
- **一次只做一个动作**：递自己的东西 ／ 替她说短 ／ 一个真问题 ／ 说你卡住 ／ 极短一句；
- P 模式上限 180 → **110 字**；
- 新增 **C11 不报告接收动作**、**C12 给自己的东西不是复读**、**C13 一次一个动作**；
- C2（承认不确定）**修订**：只在断言文本意思时才要留口子，给联想/提问/短反应不算违反；
- **管道层拦截**：C11/C9/C10 是确定性可查的，生成后正则命中就带修正说明重写（最多 2 次），
  重写次数写进报告——这是 hy4 的信号，不是耻辱柱。
  为什么不靠提示词：提示词里写反例，反例本身会被模型勾出来（v3.0 D7 已验证）。

理论依据：Rogers 反射式倾听的批评（mechanical empathy / parroting——没有姿态的做法是演戏）、
Reis 的 perceived partner responsiveness、会话分析 Pomerantz 1984 与
Heritage & Raymond 2005（复述对方措辞＝低认识立场的复读，独立的第二评价才是对等说话人）。

**非 P 语料**：`pick_nonp.py` 从《爱别离》前七章挑出 **91 段 M（0 段 S）**，
落在 `corpus_非P/`，用 `runner.py --corpus corpus_非P` 跑。
S 模式至今零样本——CLASSIFIER 在这个语料上退化成 P/M 二分类见 `logs/模式分布.md`。

> 完整版本年表、踩坑记录与复跑手册见 **`工程路径与技术回顾.md`**。

  你有合法文本的话，放进 `corpus_流派/` 重跑即可，不用改代码。
- 分类器加了**英文词表**（原来只有中文，英文输入等于全零特征）。
- 扫描结果：**P 99.4% / M 0.6% / S 0**——这批经典全是极端 P。
  它们删掉的正是"目标句/因果/冲突/收束"（合计权重 0.65），
  所以**这不是 bug，是性质**，也反证了项目对流派形态的判断。
  同时说明：**靠现行特征凑不出 M 样本**，M 区要靠新特征（推进度）或重新定义。

**② 长文本（千字级）连续伴写**（`run_long.py`）

之前都是孤立短段落。现在把一整节（1600 字左右）当系统跑，带**累积上下文**，
每段重算模式，并测两件事：模式会不会漂移、连说九轮会不会掉回口头禅。

实测（§07，18 段 / 1626 字 / 9 轮）：模式翻转 **0** 次，
相邻首句相似度最高 **0.286**（远低于 0.6 的模板线）。
**但暴露了一个短段落测不出的毛病**：给了累积上下文之后，它会**复述/总结已写内容**
（前六轮基本是改写原文）。已在 `policy.build_user` 里加了护栏，重跑后好转。

**③ 注意力机制**（`v3/attention.py` + `/api/attention` + 前端采集）

把"停笔 N 秒"这个纯时间信号，换成**停顿发生在文本的哪一层**。
依据是键盘记录研究（Inputlog, Leijten & Van Waes 2013）：
2000ms 以上的停顿对应高层规划；句中停顿是低层语言编码（**最不该打断**）；
停顿之后的删改＝R-burst，作者在做评价与修订（Galbraith & Baaijen 2019）；
停顿位置比长度更要紧（Révész et al. 2017/2019）。

| 状态 | 判据 | 行为 |
|---|---|---|
| CODING 低层编码 | 光标在**句中**停 2–8 秒 | **不说话**（最主要的沉默来源） |
| PLANNING 规划 | 句末/段末停 ≥2 秒，刚有连续产出 | 常规伴写，一个动作 |
| STUCK 卡住 | 停 ≥15 秒且无新字 | 只给"替她说短"或"一个真问题"，**不给方案** |
| POLISHING 打磨 | 30 秒内 ≥3 次删改或 ≥2 次回跳 | 只给可核对的事实，**绝不评价** |
| REVIEWING 回看 | 光标往上走且无输入 | 不说话 |
| NOT_STARTED | 文档开头 | 不说话 |

沉默状态**不调模型**，直接返回 ⊘ 卡片。
阈值是从群体研究借的先验，不是你的实测——已进埋点，等你反馈后用 hy4 校准。

### 网页切到 v3

在 `dsh-伴写/` 下建一个名为 `USE_V3` 的空文件（或 `COWRITE_V3=1`），重启服务。
装不上会自动回退到 v2 策略，不会静默出错。

### 第一轮实测（6 段占位语料，**不是真校准集**）

| 指标 | 基线 v2 | v3 |
|---|---|---|
| hy4 判定违规 | 0 / 6 | 2 / 6（T001 犯 D2/D7；T005 犯 D1/D7/D10） |
| 输出字数 | 40–87 | 58–122 |

**两个已修的坑**：
1. 禁令里写具体反面例句，模型会**把那句原样吐回来**——

## 全文阅读记忆

载入文档后，服务端会在后台按章节和语义边界逐片阅读全文，记录每一片的
内容脉络、实体关系、主题/意象、术语和关键原句，再分层归并成一份全书记忆。
文学栏底部会显示：

- `正在读全文 · 32%`：后台逐片阅读中；
- `全文已读 · 271594 字 / N 章`：全书记忆已经可用；
- `全文阅读：记忆待更新`：正文改过，旧记忆不冒充当前版本；
- 点击状态可以手动重新建立。

后续的文学对话和固定动作会同时收到：

1. **全文阅读状态**：覆盖了多少字、多少片、多少章；
2. **全书记忆**：逐片阅读后归并出的全局内容；
3. **原句检索片段**：用于核对具体引文，不冒充全文；
4. **当前章节与选区**：用户此刻在看哪里、选中了什么、正在做什么。

因此“界面按章显示”和“模型读过全文”是两件事：编辑区只装当前章，但全文
阅读记忆覆盖全文。全文翻译仍按语义片执行，避免单次上下文被挤爆。

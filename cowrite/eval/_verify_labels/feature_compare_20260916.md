## 二、私有批：18 段真跑（第一次用她的语料当输入）

`runner.py --corpus corpus_私有 --per-file 2 --arm v3`（每部等距 2 段，共 18 段，35–49 秒）。
产出 `v3/logs/反馈表_私有.md`（给她标）、`对照报告_私有.md`。

模式分布仍是 **P 17 / M 1**。输出 35–140 字。

### 抓到的缺陷 A：副文本被当成正文（已在原稿里看到过现场）

**第一遍**（未过滤）18 段里 **3 段是副文本**，而且系统对它们的反应是全篇最糟的三条：

| 段 | 原文（副文本） | 系统的回答 |
|---|---|---|
| T011 | `ThiseditionarrangedwithROGERS,COLERIDGE&WHITELTD(RCW)` | "这行字像版权页的边角料……**你介意自己以这种方式出现吗？**" |
| T003 | "李昂（1952—）台湾当代著名女作家……" | "你这段写得挺全，但**像简历**。你没提《暗夜》《迷园》……**要不要从这里开始？**" |
| T013 | 简媜散文的**推荐语**（"她的动作是如此冷静优雅……"） | "这个比喻很亮，但用在简媜身上，**是不是有点太轻了**？" |

三个都是最坏的失败模式叠加：**给一行版权声明编出文学解读**（引入原文没有的东西）、
**评价作者文本**（C3）、**给收敛型建议**（C5）。

**根因不是模型，是两个输入侧的 bug**：

1. **抽样每次都咬 `index 0`。** `runner.py` 的等距抽样是 `paras[int(i*step)]`，
   `i=0` 恒等于该文件的**第一段**——而从 epub 抽出来的书，第一段正是版权页／作者简介／序。
   0.46% 的污染率（≥71 段）之所以能命中 3/18，就是因为抽样**系统性地撞在书前页上**。
2. **导入器的噪声判据只认"ISBN／版权"这类词**，认不出作者小传和没有空格的外文版权串
   （`import_corpus.py` 会把整行压掉空白，`arranged with` 变成 `arrangedwith`）。

**已修**（两处，都验证过）：
- `runner.py`：新增 `is_paratext()`，并改成**从半格起抽** `int((i+0.5)*step)`。
- `import_corpus.py`：`NOISE_STRONG` 补 `arrangedwith|allrightsreserved|printedin|图书在版|CIP|出版发行|责任编辑|装帧设计`。

**判据只收"确定性证据"（年份区间、图书在版编目、无中文的版权串），不收"像不像简介"**。
试过"弱标记命中两条以上"的计分法，把格非正文里的一句
「…接过读者们递过来的小说集，写下自己的笔名…」**误杀**了——0.03% 的收益换一次误杀，不划算。
**宁漏不误杀。** 验证：

```
抽样 18 段 → 残留副文本 0
李昂小传 拦=True ✓   韩江小传 拦=True ✓   版权串 拦=True ✓
格非正文 拦=False ✓  历史小说「他生于乱世，毕业于黄埔」拦=False ✓
```

**修后重跑**（`反馈表_私有.md` 现为干净版；含副文本的旧版留档为
`logs/_反馈表_私有_修前_含副文本.md`）。

### 抓到的缺陷 B：干净之后就露出来的真问题——**它开始写正文了**

去掉副文本后，18 条里仍有相当一部分**越过了"给方向不给成品"**：

| 段 | 输出 | 问题 |
|---|---|---|
| T002 | "那片灰白的东西，是你吗？你跟着我走，不说话，也不走开。我跑它也跑，我停它也停。我想抓住它，手伸过去，却只抓到空气。它不回答我，也不让我走。" | **整段第一人称叙述**，可直接接进正文。铁律二直接破。D10 **没有拦住**。 |
| T006 | "水线漫过肚脐那一下，他闭眼的动作很轻。客厅的谈话声没停，他也没躲。" | **描写**（"很轻"是原文没有的），不是回应。 |
| T010 | "游客拍照，你躲开视线……这个对比**有点好笑**——你在找吃的，别人在看风景。" | 原文**没有游客拍照**（引入新东西）+ **评价**（C3）。 |
| T001 | "你哭，是认出了那不是敌人。" | 原文**没有"哭"**（替动作安动机，S1 类）。 |

另有 **4/18 出现「我读到」**（T003/T009×2/T011），即 C11 那条被论文称为"已禁用"的句式，
在提示词层**压不住**。F1（句式成了习惯）也报了"最近 3 条里 2 次"。

**结论**：私有语料把"**判层/模式可以调，输出形态调不动**"这件事，
从"长文本偶发"变成了"在作者自己的谱系上稳定复现"。
这比 §5.3 现有的三条证据更硬——因为**输入是她的正典**。

## 三、S 语料：第一次跑 S 模式的输出形态（补上"悬而未决 3"）

从 `corpus_S/` 取 3 段情节驱动正文（Conrad / Fitzgerald / Hamsun，取中段），
**同一段分别用 `mode=S` 和 `mode=P` 打 `/api/cowrite`**：

- **S 与 P 的输出形态确实不同，按钮是有效的。**
  同段两版读法明显分岔（P 版给联想、克制；S 版盯句式与推进）。
- **但 S 模式没有长度护栏**：Hamsun 那条 S 版输出约 **250 字**，
  远超 P 批的 35–140 字区间，且结构是"你说…但你没写…你怕的不是…是…"——
  **是解读定论，不是伴写**，并以"你是不是还没想好？"收尾（收敛型提问，C5/C4 双违）。
- 顺带一条：英文语料进来时输出**大量夹用英文原词**
  （realization / omission / smiled bitterly / locked up…）——
  这正是被论文称为"唯一有点信号的脚本规则"的 **C9 中英混杂**，
  在英文输入下几乎必然触发。**C9 的判定需要在论文里说明它测的是"输入语言混杂"还是"输出语言混杂"。**

**建议**：S 模式补一条与 P 等长的长度约束，并把这次的对照收进论文 §5.3。

> 还是"分类器的特性"。加上这批经典之后，才分得开。

## 三、这个结果说明了两件事

**1. 它反证了项目对流派形态的判断。**
意识流／新小说／后现代这批作品删掉的，正是"目标句、因果连接词、外部冲突、收束"
这四样——而这四样恰恰是现行分类器赖以判 S 的全部信号（合计权重 0.65）。
所以它们被压到极端 P，**不是分类器的 bug，是这批文本的性质**。
《变形记》有处境有推进也照样全 P，说明"推进"这件事靠表层词表根本测不出来。

**2. 也说明这套特征凑不出 M 样本。**
M 的定义是"情节在推进，但保持现代主义质感"。
而现行七个特征全是**表层情节信号**，它们看不见"质感"——
于是现代主义文本永远落 P，商业文本才会落到 M/S。
**要从这批语料里取 M，得先给分类器加测量"推进"的新特征**
（候选：新实体引入率、状态变化动词、段落间指代的推进度），
或者接受"M 是阈值的人为切分"这个事实并重新定义它。

这两条都是给 hy4 的待办，不是现在能靠调阈值解决的。

## 四、怎么复现

```bash
cd v3
python fetch_genre_corpus.py                     # 抓原文（已缓存则复用）→ 建语料
python scan.py --corpus corpus_流派 --out 模式分布_流派.md
python pick_nonp.py --corpus corpus_流派 --out corpus_流派非P --include-top 10 --write
python runner.py --corpus corpus_流派非P --limit 10 --arm v3 --civility
```

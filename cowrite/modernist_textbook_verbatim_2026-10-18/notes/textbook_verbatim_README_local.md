# textbook_verbatim — 伴写规则的教科书原文库

## 纪律（硬）

1. **Source of truth = 本目录中的教科书原文**，尤其：
   - `从中间开始_全部读法.md`（各章【读法：三件可以马上做的事】全文）
   - `岔路_可执行动作.md`（附录 B 总清单 + 各章「可执行…动作」原文）
   - `chap_agent_plain.txt`（《从中间开始》附：Agent 规格纯文本）
2. **伴写 SYSTEM / companion 规则必须引用上述 verbatim 读法行**，不得用对话里的口头改写、意译或「用户刚才补的一句」替换教科书方法。
3. **用户口头纠正只用于 refine fixtures / acceptance**（探针是否完整、判据何时过门），**不替换、不覆盖教科书读法操作本身**。
4. 禁止把会话 paraphrases、旧版 SYSTEM 里的自造步骤、或「知音／出声门」叙事当作方法来源。

## 3. 臂定义 → 具体开关

| Arm | 如何实例化（工程侧） |
|-----|----------------------|
| **A bare** | 关闭 USE_V3 / 不注入铁律·policy·attention·civility；仅底座补全或裸生成+同一特征头（若测的是「模型+特征」可分性，特征头与训练协议仍固定） |
| **B iron+policy** | USE_V3=on；加载铁律 + `policy.py` / SKILL；**关闭** attention 状态机与文明逐条 judge（或等价：policy 在、attention/civility 空） |
| **C full** | B + `attention.py` + 文明条款 C1–C13（`judge.py`/`bans.py`）+ 判层/⊘ 工作流全开 |
| **D optional** | 改特征实现或输入结构（新 feature set / 新表示）；**禁止**只加更长 prompt 冒充 D |

若工程无法干净消融：至少做 **prompt-ablation 近似**（系统消息 = ∅ / 铁律+policy / 全框架文本），并在结果里标明「近似消融，非二进制开关」。

## 4. 评测步骤（有标签集时）

1. **固定 holdout**：按作品或按段分层；报告 n、类别先验。  
2. 对每条样本：在 Arm X 配置下得到系统对作者状态的预测（P/M/S 或 A/B/C/⊘）。  
3. 算 **AUC**（二分类代理轴优先，与论文 0.489/0.523 对齐）与 **accuracy**。  
4. 填表：

```text
Arm | n | AUC | Acc | ΔAUC_vs_prev | notes
A   |   |     |     | —            |
B   |   |     |     |              |
C   |   |     |     |              |
D?  |   |     |     |              |
```

5. **STOP**：若 Δ(B−A)<0.02 且 Δ(C−B)<0.02 → 停止堆框架；结论写「收益递减」。  
6. 与锚点同框：把 live AUC 画在 0.489 / 0.523 参照旁（不覆盖已发表表）。  
7. **禁止**把结果写进 ClaimBoundary keepable；**禁止**动 S3。

## 5. 无完整服务时的最小可跑替代

若 `server.py` 起不来，但有：

- 标注 JSON + 文本段，且  
- 可调用同一模型 API，且  
- 有三段系统提示词文本（bare / iron+policy / full）

则跑 **offline prompt-ablation**：

```bash
# 伪流程（实现随仓库；勿在无代码时空跑）
python eval_prompt_arms.py \
  --labels path/to/labels.json \
  --arm A --system prompts/A_bare.txt \
  --arm B --system prompts/B_iron_policy.txt \
  --arm C --system prompts/C_full.txt \
  --out results/arm_curve.json
```

把 `arm_curve.json` 放到本目录 `runs/`，再写 `结果_臂曲线.md`。

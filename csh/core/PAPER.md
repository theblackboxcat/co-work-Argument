# 符号置换未产生可检出的代价
## 一项阴性结果，以及使它可信的条件

---

**摘要.** 规模定律把模型能力的突跳归因于规模的连续增长，另有工作指出这类"涌现"可能是度量选择的假象（Schaeffer et al., 2023）。本文追问一个更基础的问题：决定性样本规模的那个临界点（**涌现阈值**），其约束源是**表层符号系统**，还是符号系统之下与人类感官经验耦合的**认知基底**？据此提出**认知基底假说**（Cognitive Substrate Hypothesis, CSH）并把它落到一个可证伪的形式：若阈值由共享的关系结构决定，则置换表层符号、增补符号数目都不应移动临界规模。本文在约 1M 参数的合成关系推理任务上检验这条推论，得到一组阴性结果。（i）六个相互独立的表面（中文、英语、Lisp、数学记号、程序代码、人造词表）共享共同阈值，CV(log) = 0.0110，15 个表面配对在准确率上全部不显著；（ii）在类型结构固定、$C_{\mathrm{eff}}(3) = 24$ 恒定而符号数目增长 64 倍（$C(3)$: 24 → 1536）的条件下阈值保持平坦，36 种子下逐档配对差全部含零；（iii）两个编码完全相同的关系结构、只摧毁词义的 null 对照（`relperm` / `entperm`）在共享词表与 8 种子循环拉丁方下与真实表面在统计上不可区分（320 次运行，14 个（判据 × null）组合全部 $p > 0.10$，最小 0.128；84 个逐对检验在 Bonferroni 与 BH 校正下无一显著），在复杂度轴上同样如此（216 次运行，$n \le 6500$ 的 15 个组合全部 $p > 0.05$）。这些结果合起来排除了"这些符号系统恰好同样难"这一平凡读法：阴性结果不是无内容的。

阴性结果的成本通常被忽略，而本文的主要方法学内容正是这份成本。第一版的证据是退化的——token id 按首次出现顺序分配，使中文、数学记号、人造词表在数值层面收到逐 token 相同的输入，训练权重逐位相同（max |diff| = 0），"六个表面共享阈值"有一部分是同一个数被计算了三次。修复须同时满足两个条件：让各表面的 id 区间解耦，且让 id 区间本身成为可边缘化的一维。按表面分块的中间修复被控制实验证伪（阈值与 id 块位置单调同序，$r = +0.9368$）；6×6 循环拉丁方配平才给出正确结果。由此得到一条可复用的判据：**若删除被声称"无关"的那个变量后任务仍可解，则该变量在该形式化下不可检验**（规范 id 实验的准确率仍为 1.000）。另有两类诊断同样可复用：分母趋零可使一个 $z$ 统计量从 $z = +158$ 虚增到 $+3148$ 而无实质信号；置信区间不含 0 与 $p > 0.05$ 同时成立这一矛盾形态，其成因可在逐 seed 配对差的零值分布中直接读出。

本文同时给出这条阴性结果的边界。跨基质迁移（307 次运行）与深度扫描（432 次运行）表明，模型获得的解是**符号特化**的：迁移代价跟随签名表的符号级损伤（签名重叠 $0/6 \to +0.410$，$2/6 \to +0.245$，$5/6 \to -0.004$）而非目标结构的难度，且随推理深度 3 → 5 完全平坦。这一组合与 CSH 的强版本不相容：阈值对符号系统不变，不是因为模型掌握了跨符号的结构抽象，而是因为它记住了 token 串到类型转移的映射。本文不能区分 CSH 与一个预测完全一致的竞争解释（归纳偏置恰好与人类偏好对齐），也不能把结论外推到真实语言模型的规模轴——后者有一条明确的机制性理由（Gan & Isola, 2026）。

**关键词:** 涌现阈值；符号不变性；阴性结果；null 对照；合成任务；关系结构；度量假象

**分类:** cs.CL, cs.LG

## 1 引言

### 1.1 一个只能靠阴性结果回答的问题

大语言模型的能力在若干任务上随规模呈突跳式增长。主流解释将其归于规模的连续效应突然在能力维度上显现——能力在小模型中"不存在"，在大模型中"存在"，故无法由小模型外推（Wei et al., 2022）。Schaeffer, Miranda & Koyejo（2023）给出反诊断：许多所谓涌现是非线性或不连续度量（如精确字符串匹配）的**假象**，换成连续度量后曲线平滑且可外推；他们分析 29 个度量，25 个无线性涌现。

两方都留下了同一个未被追问的问题。若"涌现"取决于**如何测量**，测量所依托的任务结构本身由什么决定？本文把它推到符号层：

> 决定性样本规模 $n^\star$（下文称**涌现阈值**）的约束源，是表层符号系统（自然语言、人造语言、数学记号、程序代码），还是符号系统之下那套沉淀于人类感官经验、却跨越全部符号系统而共享的**认知基底**？

这一区分只能靠阴性结果回答。若阈值的约束源是表层文字与语法，把它从中文改写为 Lisp 不应移动临界规模；若约束源是认知基底，改写同样近乎免费。也就是说两种假说都预测"不变"，"观察到不变"本身不构成对任一方的支持——它同样由"所有这些符号系统恰好同样难"解释。要把这个结果变成证据，需要一个排除了"同样难"这条退路的对照，而排除它的办法只能是阴性结果：证明一个语义已被摧毁的对照（编码完全相同的关系结构、只置换标签）与真实表面同样平。这决定了本文的形态。主贡献是一组阴性结果，外加使这类结果可信所需的编码条件——本文报告的证据在第一版是退化的，修复它的代价占去正文的相当篇幅，这个比例本身就是阴性结果研究的一项经验。

### 1.2 认知基底假说与它的可证伪形式

**认知基底假说（CSH）** 分两层。**表层符号层**指编码载体，包括自然语言、Lisp 记号、数学公式、程序代码与非人造词表；它们改变 token 序列与词表规模，不改变模型需要掌握什么。**认知基底**指由人类经由感官建立、并在所有符号系统背后共享的关系概念系统，本文用其可操作的代理刻画为八项：空间、时序、物体边界、因果、计数、主体—客体、反事实、层级嵌套（Anderson, 1972；Gentner, 1983；Spelke & Kinzler, 2007）。CSH 的核心断言是：涌现阈值由认知基底的复杂度决定，表面符号只改变实现，不改变临界规模。

强版本断言阈值由**人类感官沉淀的**认知基底决定；弱版本只断言阈值对符号系统不变。本文检验的是弱版本，以及 CSH 及其弱版本都不预测的一件事：模型获得的解是否为符号特化的（§6）。若后者成立，阈值对符号系统不变的原因就不是模型掌握了跨符号的结构抽象。

弱版本给出四条可证伪预测。**P1** 只换表层符号，阈值不变——在共享词表与拉丁方配平下检验（§4.1、§4.3）。**P2** 构造脱离人类感官耦合的全新认知体系，阈值漂移——需要一个本文不具备的非人类先验形式系统（§7）。**P3** 数学、编程、逻辑共享时空因果离散计数认知，因而落在同一区间——P1 的推论，本文以 Lisp、数学记号、程序代码纳入同一带内。**P4** 小模型失败是容量不足，换符号救不了——本文不涉及参数量轴。P2 与 P4 未被本文检验，其余两条的证据见 §4。

### 1.3 本文贡献

1. 把"符号 vs 结构"之争落成一个可在百机时量级内完成的判别实验，而非依赖千卡天级的规模实验。
2. 提出并验证**语义 null 对照**（`relperm` / `entperm`）：编码完全相同的关系结构、摧毁词义的表面。这一对照使平坦结果从平凡变为非平凡，是本文阴性结果不流于无内容的唯一依据。
3. 报告一组平坦且非平凡的结果：阈值在 6 个相互独立的表面下不变（CV(log) = 0.0110），在 64 倍符号增长下不变，两个摧毁语义的对照与真实表面在统计上不可区分——表面轴 320 次运行，复杂度轴 216 次运行。
4. 定位并修复一个使对照退化为重言式的编码缺陷（token id 按首次出现顺序分配，使三个表面的训练权重逐位相同），并给出可复用的判据：删除被声称无关的变量后任务仍可解，则该变量在该形式化下不可检验。修复须同时解耦 id 区间并使 id 区间可边缘化；按表面分块的中间修复被控制实验证伪。
5. 给出两条与数据分布有关的诊断判据：分母趋零可使 $z$ 统计量虚增三个数量级；"置信区间不含 0 而 $p > 0.05$"的成因可在逐 seed 配对差的零值分布中直接读出。
6. 执行跨基质迁移（307 次运行）与深度扫描（432 次运行），给出本研究的边界：模型获得的解是符号特化的，迁移代价跟随签名表的符号级损伤而非目标结构的难度，且随深度 3 → 5 完全平坦。
7. 与 Gan & Isola（2026）的独立证据线相互印证：该文发现预训练权重邻域内的解是特化者而非通才，并把基准分数上的提升分解为"格式灌木丛"（表层，19.0%）与"推理灌木丛"（深层，12.3%）。本文在符号/结构这一轴上得到同构结论。

## 2 相关工作

### 2.1 涌现的度量争议

Wei et al.（2022）系统陈述了涌现能力的现象与定义。Schaeffer, Miranda & Koyejo（2023）对 29 个度量做了系统评估，论证不连续或非线性度量会把平滑的性能改善人为地呈现为突跳，并据此提出"能力连续增长 + 度量不连续"这一解释。这是本文的直接方法学动机：既然阈值本身是度量的产物，则任何关于阈值的断言之前都须固定度量并检查其对度量选择的敏感性。本文因此把判据（准确率首次越过 0.60）显式写出并做敏感性检查（§4.4），而非依赖"某个模型突然变好"的目视判断。

Merrill, Sabharwal & Smith（2023）在自动机任务上给出一个相关的结构性观察：Transformer 倾向于学到**捷径解**，用与推理步数无关的浅层计算精确模拟任意有限状态自动机。这提示模型的复杂度需求由**任务结构的代数性质**而非输入长度决定。本文在更小的尺度上呼应这一点：决定阈值的是类型结构（$C_{\mathrm{eff}}$），而不是符号数目（$C(k)$、$N_{\mathrm{REL}}$）。

### 2.2 结构与符号的分离

CSH 属于把符号系统的底层共享结构当作约束源的立场，这在认知科学中有独立传统。Gentner（1983）的结构映射理论主张类比映射规则**只依赖知识表示的句法属性，而不依赖其具体内容**；这是本文方法学的认知侧对应物——`relperm` 对照编码完全相同的关系结构、只置换标签，若结构是约束源，置换不应改变难度。Spelke & Kinzler（2007）综述婴儿与跨物种研究，提出人类认知建立在若干**核心知识系统**之上，每套系统有其跨任务、跨年龄、跨物种、跨文化的**签名式限制**（signature limits）；本文的基质代理是对这套签名式限制的形式化——类型结构提供"哪些实体可参与同一操作"这一可辨识的边界，把两个本可互换的符号在统计上区分开来。Anderson（1972）的层级性论证提供结构层面的先验；本文的三类型—两出边结构是一个最小的层级实例，其复杂度代理 $C_{\mathrm{eff}}(3) = 24$ 独立于表层符号数目。

表征学习一侧的两项工作共同支持一个本文采用的方法学立场：结构约束可以在不增加显式监督的情况下被注入并被学到。Mordatch & Abbeel（2018）表明多智能体交互中可以涌现出具备确定词汇与句法的组合语言，其结构来自**共同任务的约束**而非符号本身。Bahdanau, Cho & Bengio（2015）的注意力机制把"对齐"从外部离散模型变为端到端可微操作，即**结构化的软权重**足以承载跨序列的对应关系。

### 2.3 与 Neural Thitches 的关系

Gan & Isola（2026）测量**预训练权重高斯邻域内**"能改善任务表现的解"所占的比例（*solution density*），发现该密度随模型规模单调上升：小模型处于"草堆寻针"区（好的解稀疏），大模型进入"灌木丛"区（任务专家稠密）。三处与本文构成互补。其一，他们把基准分数上的提升分解为**格式灌木丛**（答案格式被修正，19.0%）与**推理灌木丛**（模型真的解决了原先解不出的推理题，12.3%），并明确指出观察到的效应"可能并非来自根本不同的推理形式，而是相对肤浅的差异"；本文 §6 在符号轴上得到同构结论。其二，他们的采样解是特化者；本文训练的模型也是特化者，它特化于**特定的符号到类型转移的映射**，只有在该映射完好时才迁移。其三，他们的"平台区制"（预训练已使测试任务饱和）与本文在深度扫描中遇到的天花板效应同源。

关键差别在于变化的轴。他们变化**模型规模**与**预训练分布多样性**，度量权重空间的解密度；本文变化**训练样本数**与**关系结构复杂度**，度量的量是样本复杂度意义上的涌现阈值。二者是"找到好解有多容易"这一问题的两个不同投影，本文不与之竞争，而构成同一图景的两个截面。正因如此，本文明确拒绝把结果外推到规模轴（§7）——Neural Thitches 恰恰给出了**为什么**规模轴可能改变结论的具体机制：更大模型有更稠密、更多样的解灌木丛。

## 3 操作化与实验设计

本文的阴性结果对编码条件敏感：同一组实验在一种编码配置下给出"平坦"，在另一种配置下给出"完全相同"。这一条件在 §5 给出并核验，本节只描述主实验所用的配置。

### 3.1 阈值与复杂度旋钮

本文把"涌现"操作化为一个**可计算、不依赖目视判断**的量。给定基质 $S$、表面 $\sigma$、训练样本量 $n$ 与种子 $z$，记 $\mathrm{acc}(S,\sigma,n,z)$ 为留出集上深度-3 任务的准确率；定义判据 $\tau = 0.60$（随机基线 $1/18 \approx 5.6\%$ 的十倍以上，远未饱和），涌现阈值 $n^\star(S,\sigma)$ 为 $\mathrm{acc}$ 首次越过 $\tau$ 所需的**不同训练样本数**，在 $\log n$ 轴上对越界点线性插值。三条设计要求：不依赖度量选择——$\tau$ 的选择会移动 $n^\star$ 的绝对值，因此报告的全部是**同一 $\tau$ 下的组间比较**（§4.4）；插值而非跳跃——用 $\log n$ 插值避免 5000 与 6500 之间的分辨率损失；种子级 bootstrap——每个阈值先按种子分别估计，再对种子重采样（4000 次）给出 95% 置信区间。

给定 $k$ 个关系的合法序列数目为 $C(k) = \mathbf{1}^\top M^{k-1}\mathbf{1}$，其中 $M_{ij}=1$ 当且仅当关系 $i$ 的**值域类型**等于关系 $j$ 的**主域类型**；它是深度 $k$ 上的路径计数，即搜索空间大小。$C(k)$ 不是合适的复杂度旋钮：以它为旋钮的实测给出相反方向（$C(3)$ 从 8 增到 150 时阈值反而下降；见附录 B 表 B1），诊断显示 branching factor 高时约束变弱、模式匹配即足够。本文因此改用**有效复杂度** $C_{\mathrm{eff}}(k)$，即模型**真正能共享统计量**的类型转换签名（$\mathrm{sig}(r) = (\mathrm{dom}(r), \mathrm{ran}(r))$）去重后的计数，而不是原始序列数。$C(k)$ 保留为报告量。

**语义 null 对照.** 仅有"所有表面阈值相近"是**平凡**的：它同样由"所有这些符号系统同样难"解释。本文因此引入两个 null 对照。**`relperm`**（关系标签随机置换）保持实体标签不变，关系标签按固定种子重排。**`entperm`**（实体标签随机置换）保持关系标签不变，实体标签按固定种子重排。二者都保留"一个事实有 5 个 token"的结构配平，因此与真实表面的差别**只在符号身份**。若 null 对照的阈值落在真实表面带内，"平坦结果"就排除了"词义本身有难度"的读法；若落在带外（如显著更难），则只能得出"这些符号系统同样难"。§4.3 报告 null 落在带内。

### 3.2 基质、表面与 token 配平

给定一个深度-3 链式关系推理题：起始实体 $e_0$ 经三个关系 $r_1,r_2,r_3$ 到达 $e_3$，问 $(e_0, (r_1,r_2,r_3)) \mapsto e_3$。每题含 9 条事实（3 条链 + 5 条干扰 + 1 条查询），并保证从 $(e_0, \mathrm{seq})$ 到答案的路径**唯一**。18 个实体，故随机基线为 $1/18 \approx 5.6\%$。

type 结构固定为 3 个类型、每个类型恰好 2 条出边；参数 $\texttt{mult}$ 决定每个类型转移由多少条具体关系实现，故 $N_{\mathrm{REL}} = 6 \cdot \texttt{mult}$：

| mult | $N_{\mathrm{REL}}$ | branching | $C(3)$ | $C_{\mathrm{eff}}(3)$ |
|---|---|---|---|---|
| 1 | 6 | 2 | 24 | 24 |
| 2 | 12 | 4 | 192 | 24 |
| 3 | 18 | 6 | 648 | 24 |
| 4 | 24 | 8 | 1536 | 24 |

类型结构（即约束力）在每个水平完全一致，变化只有具体关系符号的数目：$C(3)$ 增长 64 倍而 $C_{\mathrm{eff}}(3)$ 恒为单一值 24。这一构造使复杂度轴与符号轴可分离。

**严格 token 配平.** 8 种表面的自然编码长度不同：中文 46、数学 38、代码 30 token。若直接比较阈值，"表面无效应"只说明这些表面的**序列长度**相近，与符号无关。因此每条事实强制恰好 5 token；330 次运行实测输入长度**全部为 46**，运行时以 `assert` 强制此不变量。一个表面的一条事实的 5 个 token 分别为：中文 `甲 含 乙 。 ，`、English `A is r B .`、Lisp `( r A B )`、math `A ρ B ; ~`、code `A r B ) ;`、alien（3 音节非人造词，seed=20240）`ka tsu no | ~`，以及两个 null 对照（English 编码，标签随机置换）。图 1 给出任务与编码的整体示意。

![图 1：实验结构。(a) 类型化关系基底：3 个类型、全部 6 条有序类型转移、每类型 2 条出边，$C_{\mathrm{eff}}(3)=24$ 在每个水平相同。(b) 符号倍增：每个类型转移由 mult 条具体关系实现；$N_{\mathrm{REL}}$、branching、$C(3)$ 增长而类型结构不变。(c) 一条事实在 8 种表面上的编码，全部严格 5 token，每臂 9 条事实 = 46 token。](../paper_figs/fig1_task.png)

### 3.3 训练与实验网格

小型 Transformer 编码器：$d_{\text{model}}=128$、$L=4$ 层、$H=4$ 头、$d_{\text{ff}}=256$，约 1M 参数，tied embeddings，LayerNorm + MultiheadAttention + GELU 前馈，掩码用 `key_padding_mask`。AdamW + OneCycleLR，$lr=3\times10^{-4}$，batch 32，1 epoch。词表在模型实例化前遍历全量语料填充，否则词表大小在构造时未定、索引越界。规模刻意压小：目标是在 CPU 上 1.5 小时跑完主实验，使结果可复现，而非只在有集群时存在。

主实验两个臂。**臂 S**（表面不变性）：8 表面 × 5 个 $n \in \{2000,3000,4000,5000,6500\}$ × 6 种子 = 240 次运行，基质固定为 mult=1。**臂 K**（复杂度）：mult $\in \{2,3,4\}$ × 5 个 $n$ × 6 种子 = 90 次运行（mult=1 与臂 S 的 English 臂共享），表面固定为 English。合计 330 次运行、零错误。另有两个约束必须从一开始就成立，否则本节的阴性结果无从解释：粗扫阶段仅用 2–4 种子时曾据两个表面阈值的差异（2899 与 5650，相差 95%）误判"CV 支持表面无效应"，因此主实验一律用 6 种子并引入 null 对照；以阈值度量效应量时 $n$ 网格必须**括住基线的判据交叉点**，否则阈值被钉在网格边界上（这一条在 §6.2 的一次设计中失效过，其后果见 §5.3）。

### 4.3 语义 null 对照

只有表面轴与复杂度轴上的"平坦"都不足以支持本文的主张——它们与"这些符号系统恰好同样难"一致。本节给出排除这条退路的证据。

**共享词表.** 8 个表面（6 真实 + 2 null）编码进同一个 `Vocab`，vocab 规模恒为 225、token 数恒为 46（320/320 格点全部满足）。此前 null 臂与真实表面用了不同的词表规模（225 对 169），而参数量与随机初始化都由词表规模决定，配对差里因此混入了模型规模差异。

**8 种子循环拉丁方.** $\mathrm{slot} = (\mathrm{surface\_index} + s) \bmod 8$，8 个种子使每个表面恰好遍历全部 8 个 id 区间各一次，slot 边际计数各为 8（完整配平表见附录 B 表 B4）。退化守卫的检验结果是：上一轮 `en`/`relperm`/`entperm` 在 30/30 个格点上逐位相同（这会让 $p$ 恒等于 1，检验在空转），本轮最高逐位相同比例是 `zh`–`en` 的 0.225，完全退化的配对 0 对。

在 $n = 6500$ 处真实六表面准确率均值 0.8313 对 null 臂均值 0.8273（各档完整均值见附录 B 表 B5）。统计量 A（null 阈值 − 真实表面阈值均值，标签重排置换 10,000 次）全部阴性：

|---|---|---|---|---|
| 0.45 | $+27$ | 1.0000 | $-549$ | 0.1279 |
| 0.50 | $-85$ | 1.0000 | $-415$ | 0.5006 |
| 0.55 | $+19$ | 1.0000 | $-269$ | 0.6203 |
| **0.60** | $+86$ | 0.8772 | $-204$ | 0.5000 |

统计量 B（null 与每个真实表面逐对配对，符号翻转置换）给出 84 个检验（$2$ null × $6$ 真实表面 × $7$ 个 $\tau$）：未校正 $p \le 0.05$ 的组合 0 个；Bonferroni $\alpha' = 5.95 \times 10^{-4}$ 下显著 0 个；Benjamini–Hochberg $q \le 0.05$ 下显著 0 个。

早先一轮的两个统计量在 $\tau = 0.55$ 上给出过不同结论（与均值配对得到 14/14 不显著，逐对配对得到 `entperm` 的 $p = 0.019$，见附录 B 表 B2）。根因是词表规模不匹配与检验形式敏感在 6 种子、5 个 $n$ 档的分辨率下把 S2 变成欠定的；共享词表与拉丁方配平一次消除了两者。修好后两种统计量在全部 7 个（$\tau$, null）组合上一致，欠定问题不复现。

**一处必须如实记录的现象.** `mult = 4` 档上，`en`/seed1 在 $n \le 11000$ 恒在 0.075–0.200，到 $n = 14000$ 才跳到 1.000；`relperm` 的 seed1 与 seed3 也是晚熟（附录 B 表 B7）。这个种子没有被当作训练失败剔除——`steps` 字段显示 mult = 4 的 18 个格点步数集合完全相同（$\{62, 93, 125, 156, 203, 265, 343, 437\}$，只随 $n$ 变），训练步数正常。它把 `mult = 4/en` 在 $n = 6500/8500/11000$ 的均值从约 1.00 压到 0.86，制造出一条假"平台"；而按结果剔掉这个种子就是按结果选样本。晚熟不是孤例，而是 mult = 4 这一档的特征——关系种类数更高时，到达阈值所需的 $n$ 分布更宽。

### 4.4 判据敏感性

$\tau = 0.60$ 的选择会移动所有阈值的绝对值，因此需要检查组间结论是否依赖它。在 $\tau \in \{0.45, 0.50, 0.55, 0.60, 0.65, 0.70, 0.75\}$ 上的重算显示（完整表见附录 B 表 B8）：CV(log) 恒为 0.009、极差恒为 21.7–23.2%、臂 K 的 log–log 斜率恒在 +0.018 至 +0.021 之间、$r$ 恒在 +0.139 至 +0.147 之间。S1 与 K-A 对判据选择完全不敏感。

不稳健的量已定位，其失败方式本身就是数据。S2 的 null 落位在 7 个判据中的 2 个（$\tau = 0.50$ 与 0.65）失败，检查细节后可精确定位原因，且这一失败不是符号置换变难：$\tau = 0.50$ 时 `relperm` 与 `entperm` 的阈值均为 3,821，与真实表面带的下界 3,821 完全相等——它们与 `en` 并列构成带的下端，而非低于带外；$\tau = 0.65$ 时 `relperm` = 4,049 等于下界 4,049，仅 `entperm` 低于下界 1,026 例。也就是说 S2 的判定依赖于 null 恰好不成为唯一的最难表面；当真实表面的最低者与 null 并列时，数值上的"带内"是一个零测度的边界情形。这一观察直接产出了两项补救——把 S2 从集合包含关系改为统计检验、在每个复杂度水平重跑 null——两者分别在 §4.3 与附录 B 表 B6 中执行。修复后的状态：

| 检查项 | 修复前（退化编码，60 次运行） | 修复后（S2L，320 次运行） |
|---|---|---|
| null 落位 | 7 个判据中 2 个失败（$\tau = 0.50/0.65$） | 集合包含不再作为判据；改用统计检验 |
| 统计量 A（与均值配对） | 14/14 不显著 | 14/14 不显著（最小 $p = 0.128$） |
| 统计量 B（逐对配对） | `entperm` 在 $\tau = 0.55$ 上 $p = 0.019$ | 84 个检验无一显著（Bonferroni 与 BH 校正下均为 0） |
| 两种统计量是否一致 | **否**（结论依赖统计量形式） | **是**（7 个（$\tau$, null）组合全部一致） |
| 词表规模 | null 225 对真实 169 | 全部 225（共享 `Vocab`） |

这张表也是本文方法学内容的一个缩影：上表那个"在 7 个判据上都稳健"的 CV(log) = 0.009，完全是退化的产物（§5.1）。一个数字对某个设计选择不敏感，不构成它为真的证据。

## 5 使阴性结果可信的条件

阴性结果的负担与阳性结果不同。阳性结果只需说明"我看见了什么"；阴性结果必须同时说明"我凭什么没看见别的东西"。本节给出本文两条可复用的判据，并说明它们各自排除了哪一种伪影。

### 5.1 判据一：删除被声称无关的变量后，任务是否仍可解

复核 36 种子数据时发现，六个"真实表面"只产生四个彼此独立的数字：`zh` = `math` = `alien`（vocab 31），`en` = `relperm` = `entperm`（vocab 31），`lisp`（30），`code`（30）；逐位相同的格点数为满分 180 中的 180/180（完整矩阵见附录 B 表 B2a）。

机制在编码里。`model.py` 的 `build_vocab` 按**首次出现顺序**分配 token id：

```python
for r in rendered_list:
    v.add("<bos>")
    for t in r["tokens"]: v.add(t)      # 首次出现 -> 下一个 id
    for t in r["target"]: v.add(t)
```

每条事实恰好 5 token、查询模板固定，因此每个 token 首次出现时所占据的**角色位置在所有表面间是同一套**。于是 id 序列只反映角色结构，与 token 字符串无关。实测（同一 30 个问题）：`zh` vs `math`、`zh` vs `alien` 各 30/30 条 id 序列完全一致，而三者的 token 字符串完全不同（`甲 含 乙 。 ，` vs `x_0 ∈ x_1 ; ~` vs `sor dop tep | ~`）。训练出的权重**逐位相同**（`max |weight diff| = 0.000e+00`）。

这不是特殊情形，而是任务形式化的必然推论。把 token 身份完全移除（只留"槽位 + 关系序号 + 实体序号"的规范 id）并随机置换关系 id，**准确率仍为 1.0000**。符号身份可以被完全删除而任务仍可求解，因此在本任务中符号身份不携带信息——这既解释了为什么原设计会退化，也说明"符号无效应"在这一形式化下**不可能被证伪**。

由此得到判据一：**若删除被声称"无关"的那个变量后任务仍可解，则该变量在该形式化下不可检验。** 原稿中"`en`/`relperm`/`entperm` 在 30/30 个格点上逐位相同"曾被当作比"落在带内"更强的证据，实际上是同一个输入被计算了三次。

**修复需要两个条件，不是一个.** 仅让每个表面占用不相交的 id 区间是不够的：最初的修复按表面顺序分块，得出的阈值与 **id 块位置**完全单调同序（$r = +0.9368$）。控制实验固定同一表面、同一数据、同一种子，只改变它的 id 块位置，六档准确率为 0.586 / 0.323 / 0.726 / 0.983 / 0.247 / 0.404，极差 0.1675–1.0000，方差分解 between-slot 0.064 / within-slot 0.062、比值 1.04——与种子噪声同量级。机制是 `torch.manual_seed(seed)` 后 embedding 按固定顺序初始化，token 落在哪个 id 区间决定了它分到哪一行随机初始化。这是初始化运气，不是符号身份效应。

因此正确修复须让 id 分配与表面身份解耦，**并且**把 id 区间本身变成可边缘化的一维：用 6×6 循环拉丁方 $\mathrm{slot} = (i + s) \bmod 6$，使每个表面在 6 个种子上恰好经历全部 6 个 id 区间各一次。修复后（180 次运行）CV(log) = 0.0110，15 个表面配对全部不显著（§4.1）。

**图 3（原设计，保留作对照）** 各表面的阈值与 95% 置信区间。此图为修复前的退化版本：`zh`/`math`/`alien` 三者的"相同"来自本节的编码退化，不是独立测量。保留它是因为删除这一对照会掩盖一个真实的方法学教训。

### 5.2 判据二：报告区间估计或检验前，先检查它的输入分布

这一项发生在**数据分析**层面：同一份数据，两个都合理的统计量会给出相反的结论，而它们矛盾的方式指出了数据里的一个结构问题。

第一种形态是分母趋零。把 S2 从"集合包含"升级为"统计检验"时，第一版用 $z = (\bar n^\star_{\text{null}} - \bar n^\star_{\text{real}}) / \mathrm{sd}_{\log}(n^\star_{\text{real}})$，得到 $z = +158$ 到 $+3148$，看起来极显著。这是分母伪影：由于 §5.1 的退化，六个真实表面的阈值几乎相同，$\mathrm{sd}_{\log}$ 只有 $10^{-3}$ 量级，任何除法都会被放大。改用**逐 seed 配对差的均值**后，数值回到合理范围（$+100$ 到 $+396$，CI 宽约 $\pm 800$），与种子间波动一致。

第二种形态更微妙，因为它不来自任何一处计算错误。把迁移代价按深度作回归时，`Thighovl` 给出

$$\mathrm{gap}_{\mathrm{depth}\,5} - \mathrm{gap}_{\mathrm{depth}\,3} = +0.0120,\quad 95\%\,\mathrm{CI} = [+0.0016,\,+0.0210],\quad p = 0.0923$$

置信区间不含 0，而置换检验的 $p$ 大于 0.05。两者不可能同时正确。诊断办法不是挑一个信，而是回头看逐 seed 配对差里有什么：

```
Thighovl depth 3, n=6500 :  +0.0000 +0.0000 +0.0000 +0.0000 +0.0000 −0.0050
Thighovl depth 3, n=8500 :  +0.0000 +0.0000 +0.0000 +0.0000 +0.0000 +0.0000
Thighovl depth 3, n=11000:  +0.0000 ×6
```

深度 3 的这一格在 $n \ge 6500$ 上**已经饱和**：TT 与受损基质都学会了这个变换，于是配对差恒为 0。这些 0 的含义是"两者都会了"，不是"两者没差别"。把它们计入均值，斜率完全由深度 5 那几个尚未饱和的格点驱动；而 bootstrap 百分位 CI 在大量 0 值之下会偏窄，给出"不含 0"的假象。符号翻转置换则在 0 值过多时功效不足，报出 $p = 0.092$。

按 $\mathrm{acc} \ge 0.99$ 显式剔除天花板格点后（有效格点 18 → 10），点估计的**绝对值变大**了（$+0.0120 \to +0.0256$），但区间变宽、$p$ 从边缘显著变成完全不显著（0.092 → 0.495，共同种子 6 → 3，完整表见附录 B 表 B9）。也就是说，"CI 不含 0"这个假象不是信号被低估，而是分母被 0 值压扁。

由此得到判据二：**在报告任何区间估计或检验结果之前，先检查它的输入分布，尤其是零值与饱和值的比例。** 特别地，"CI 不含 0 而 $p > 0.05$"这个组合说明两个统计量读的不是同一部分信息——bootstrap 百分位法对 0 值敏感（区间偏窄），符号翻转法同样对 0 值敏感但方向相反（功效不足）——此时应做的事只有一件：把逐 seed 配对差打印出来，数一数里面有几个 0，以及 0 集中在哪一档。

### 5.3 一条贯穿全文的设计约束

§3.3 与 §6.2 各有一次违反同一条约束：阈值的可估计性要求 $n$ 网格覆盖基线的判据交叉点，而用差值定义的效应量在基线饱和时会失真。两者叠加会产生一个反转结论的假象——§6.2 中代价看起来在 depth 4 达峰后回落（$\mathrm{Tlowovl}$: $0.410 \to 0.576 \to 0.501$），据此会误判"趋势反转"；depth 4 与 depth 5 的网格下界都高于基线交叉点，且 depth 5 的基线已饱和到 0.986，效应量的上界因此被压缩。补齐网格（depth 4 加 2500/3500，depth 5 加 3000/4500，共 96 次低 $n$ 运行）后"上升"消失，真实模式是平坦。根因是用 2 种子先导探测估计交叉点，系统性低估了所需范围——这与 §3.3 的低种子问题是同一类错误，在设计新实验时重复出现。§4.3 的扩展网格也撞上同一个约束的另一侧：$n = 8500/11000/14000$ 三档上 $\mathrm{acc} \ge 0.99$ 的格点占 191/216 = 88.4%（附录 B 表 B10），补上界买到了阈值可测性，代价是分辨率——信息量只能读 $n \le 6500$ 的部分。

可复用的形式是：**报告任何基于阈值的比较之前，先检查每个条件下的阈值是否被网格钉住，并检查基线是否已饱和。** 本文把这两项检查写成自动的 sanity 行（`analyze_depth_gap.py`）而不是事后检查。

## 6 得到的解是符号特化的

§4 的阴性结果有两个可能的读法：模型掌握了跨符号的结构抽象，因此符号无关紧要；或者模型记住了 token 串到类型转移的局部映射，因此符号无关紧要但机制是记性的。本节区分它们。这是本文的边界，也是与 CSH 强版本不相容的那部分证据。

### 6.1 跨基质迁移：签名表混淆

区分猜想 A（阈值的约束源是人类感官建立的认知基底）与猜想 B（归纳偏置恰好与人类偏好对齐，两者无关）需要一个正交操作。§3.1 给出的设计是 $2\times2$ 迁移矩阵：训练基质 × 测试基质，两个基质在 $N_{\mathrm{REL}} = 6$、六个关系符号、输入 46 token、vocab 31、训练步数上严格配平，唯一变化是类型分配表 `assign`。typed 的 branching 为 2、$C(3) = 24$、$C_{\mathrm{eff}}(3) = 24$；untyped 的 branching 为 3、$C(3) = 57$、$C_{\mathrm{eff}}(3) = 9$。四个格点各与本行基线比较——绝对准确率跨行不可比，因为两个基质难度不等（阈值相差 757 个样本）。

![图 5：(a) 2×2 迁移矩阵的学习曲线：实心标记为两个行内基质 TT（typed→typed）与 UU（untyped→untyped），虚线空心标记为两个迁移格点 TU 与 UT；阴影为 ±1 s.d.（6 种子），横轴为训练样本数（对数），蓝色横虚线为判据 $\tau=0.60$，红色点线为随机基线 $1/18$。(b) 仅重命名关系标签、基质完全不变的 null 对照曲线（TTp、UUp），与 (a) 同轴。](../paper_figs/fig5_transfer_curves.png)

迁移格点确实系统性低于各自基线：按种子配对的逐 $n$ 准确率差（正 = 迁移有代价）为 TU $+0.245$ [+0.176, +0.301]、UT $+0.241$ [+0.211, +0.270]，阈值空间对应 $+3{,}411$ [+2,030, +4,683] 与 $+3{,}196$ [+489, +7,378] 个样本。若止于此，A 似乎得到支持。

**承重对照给出了否证.** 仅重命名关系标签、基质结构完全不变的 null 臂，代价为 TTp $+0.324$ [+0.233, +0.386]、UUp $+0.229$ [+0.184, +0.268]——与迁移代价同量级，前者甚至更大。一个不改变任何结构的干预复现了全部现象。

原因在逐符号比对中显现：6 个关系符号中只有 2 个（符号 0 与 4）保留原义，4 个被打乱。一个仅记住"token 串 → 类型转移"的模型恰好损失这 4 个，无需引用任何难度差异。2×2 设计因此在"结构变化"与"签名表破坏"之间是纠缠的，其结果不可归因。

Thighovl 完全免费（CI 含零），而它的结构比 typed 更难（$C_{\mathrm{eff}}$ 13 < 24，branching 相同）——它只破坏了 1 个签名。Tlowovl 代价最大（$+0.410$），与 untyped 难度完全相同（branching 3.0）但签名表全毁。代价随签名破坏程度单调变化：$0/6 \to +0.410$，$2/6 \to +0.245$，$5/6 \to -0.004$。

代价跟随的是签名表被破坏了多少，而非目标结构有多难。猜想 A 原本主张类型结构是模型为跨过阈值必须专门习得、且习得绑定于训练基底的东西；一个"结构更难但签名表完整"的基质被免费迁移，直接排除了这一读法，A 在本实验中被证伪，且证伪方式明确。

**但这不等于支持 B.** 反向结果只移除了 A 所需的机制；B 以及"模型学到的是符号级记忆"这一更朴素的解释，仍是多个存活解释之一。本实验实际支持的第三种解释是：模型在 depth-3 追踪任务上主要学到 token 串到类型转移的局部关联，而非可迁移的类型结构抽象。

### 6.2 深度扫描：正面检验"符号记忆"解释

上节留下三种解释、一种未被正面检验。深度是唯一能区分"符号记忆"与"结构抽象"的轴，而本文此前全部实验都把深度固定在 3。两种解释给出相反的预测：**符号记忆**（一次性查表）预言迁移代价**平坦**，因为签名表在 depth 3 与 depth 5 都是同样 6 项；**结构抽象**（沿链递归）预言迁移代价**上升**，因为链越长错误类型转移累积越多。

统计量不用"准确率差在网格上的均值"——它受 §5.3 的天花板效应污染。改用基线刚跨过判据那一刻、受损基质低多少：$\mathrm{gap} = \tau - \mathrm{acc}_{\text{cell}}(n^\star_{\mathrm{TT}})$。它在每个深度都以"基线刚学会"为参照点，因而与 $n$ 的绝对尺度无关，也不受基线饱和影响。

432 次运行的结果（depth 3 为 120、depth 4 为 144、depth 5 为 168；三个深度的 TT 阈值均 6/6 种子可估且无钉边）：

| 测试基质 | 签名重叠 | depth 3 | depth 4 | depth 5 | 斜率 95% CI | 判定 |
|---|---|---|---|---|---|---|
| Thighovl | $5/6$ | 0.003 | $-0.007$ | 0.038 | $[+0.003, +0.033]$ | 微升（幅度近零） |
| **TU** | $2/6$ | 0.305 | 0.260 | 0.327 | $[-0.029, +0.044]$ | **平坦** |
| **Tlowovl** | $0/6$ | 0.482 | 0.463 | 0.495 | $[-0.017, +0.027]$ | **平坦** |

![图 9：(a) 四个测试基质的"跨判据时刻差距"随深度变化。水平虚线为平坦预测。(b) 基线 TT 的阈值随深度上升（3,970 → 4,416 → 5,468），确认深度的确在改变任务难度——即深度轴是有效的。](../paper_figs/fig9_depth_scan.png)

真正承载代价的两个基质（TU 0.30、Tlowovl 0.49）随深度完全平坦。代价的量级由签名重叠度决定（$5/6 \to \sim 0$；$2/6 \to 0.30$；$0/6 \to 0.49$），与深度无关。这正是"一次性签名表查表"的预测：六项映射学一次，depth 3 与 depth 5 的代价相同。§6.1 的"符号级记忆"读法因此通过了一个它本可能失败的检验，无需修正。

平坦兼容符号记忆，但不证明记忆——模型也可能因与记忆无关的原因不做复合。结合 §6.1，符号记忆是当前最简解释。本结论限于约 1M 参数、depth 3–5。

### 6.3 深度与数据量的解耦

§6.2 的统计量以"基线刚学会"为参照点，消掉了 $n$ 的绝对尺度，因此避免了深度与数据量的纠缠。但它留下的原话是关于 `gap` 这个统计量的；若直接比较不同深度上的准确率差 penalty，纠缠就会回来——那时"penalty 不随深度上升"与"penalty 随 $n$ 上升、只是三个深度的 $n$ 分布不同"是不可分辨的。

解耦设计为 3 个深度 × 4 个变换 × 同一组 6 个 $n$ 档（4000 / 5000 / 6500 / 8500 / 11000 / 14000）× 6 种子 = 432 次运行。第一步确认深度轴有效：TT 基线的对 $\log n$ 梯形积分随深度单调下降（area 0.9401 → 0.9160 → 0.7552），深度越大确实越难，因此"penalty 与深度无关"不能被解释为"depth 没起作用"。

第二步是 §5.2 那个矛盾形态的完整版本：`Thighovl` 的 $d5 - d3$ 给出 $+0.0120$、CI $[+0.0016, +0.0210]$、$p = 0.0923$，CI 不含 0 而 $p > 0.05$；根因是 depth 3 在 $n \ge 6500$ 上已饱和、配对差恒为 0。第三步剔除天花板格点（TT 与变换均 $\mathrm{acc} \ge 0.99$，有效格点 18 → 10）后重算，三个变换一致：TU $-0.0196$ CI $[-0.2610, +0.3425]$ $p = 1.000$、Tlowovl $-0.0556$ CI $[-0.4063, +0.4338]$ $p = 1.000$、Thighovl $+0.0256$ CI $[-0.0233, +0.0588]$ $p = 0.495$（完整六行见附录 B 表 B9）。$n$ 方向（同一 depth 内跨 $n$ 档，全量口径）同样无关：TU $+0.0186$ CI $[-0.0361, +0.0859]$ $p = 0.712$；Thighovl $+0.0031$ CI $[-0.0106, +0.0203]$ $p = 0.809$；Tlowovl $+0.0192$ CI $[-0.0585, +0.0993]$ $p = 0.780$。

三条限定必须与结论同时出现。其一，"与 $n$ 无关"只在全量口径下成立，而全量口径含饱和格点；剔天花板后 $n$ 只剩 4000 与 5000 两档，不构成斜率，无法复算这一句。其二，剔天花板后只剩 3 个共同种子，功效不足——这是"未发现效应"，不是"确认无效应"。其三，§6.2 的 `gap` 统计量不受这两条限制影响，因为它本身以"基线刚学会"为参照；本节的价值在于确认换用最朴素的准确率差读法时结论不变。

## 7 结论与限制

本文的问题是：涌现阈值的约束源是表层符号系统，还是认知基底。这个问题只能靠阴性结果回答，而阴性结果的可信度需要单独建立。在约 1M 参数的合成关系推理任务上、合计约 4,500 次运行中，本文的结果是：

**（一）符号置换在两条轴上都不产生可检出的代价.** 表面轴上，六个相互独立的表面共享共同阈值（CV(log) = 0.0110，15 个配对全部不显著）。复杂度轴上，$C_{\mathrm{eff}}(3) = 24$ 恒定而 $C(3)$ 增长 64 倍，阈值平坦（36 种子下逐档配对差全部含零）。关键的一条是语义 null 对照：两个编码完全相同的关系结构、只摧毁词义的表面与真实表面在统计上不可区分（表面轴 320 次运行，14 个组合全部 $p > 0.10$、最小 0.128，84 个逐对检验在两种校正下无一显著；复杂度轴 216 次运行，$n \le 6500$ 的 15 个组合全部 $p > 0.05$）。这一条排除了"这些符号系统恰好同样难"的平凡读法，是阴性结果不流于无内容的依据。

**（二）这份阴性结果一度是被伪装的重言式，修复它需要两个条件.** 原设计的 token id 按首次出现顺序分配，使三个表面在数值层面收到逐 token 相同的输入，训练权重逐位相同，"六个表面共享阈值"有一部分是同一个数被计算了三次。修复须同时**解耦 id 区间**并**使 id 区间成为可边缘化的一维**：只做前者会被 id 块位置污染（$r = +0.9368$，控制实验中 slot 间方差与种子噪声同量级），只做后者无法防止归一化算法的隐式依赖。可复用的判据是：**删除被声称无关的变量后任务仍可解，则该变量在该形式化下不可检验**——本文的规范 id 实验准确率仍为 1.0000。配套的一条是**报告任何区间估计或检验前先检查输入分布的零值与饱和比例**："CI 不含 0 而 $p > 0.05$"同时成立这一形态，其成因就在逐 seed 配对差里（深度 3 的 $n \ge 6500$ 各档恒为 0），此时该做的事是把配对差打印出来数零，而不是挑一个统计量信。

**（三）模型的解是符号特化的，这与 CSH 的强版本不相容.** 迁移代价跟随签名表的符号级损伤（重叠 $0/6 \to +0.410$，$2/6 \to +0.245$，$5/6 \to -0.004$），而非目标结构的难度；代价随推理深度 3 → 5 完全平坦（TU 与 Tlowovl 的斜率 CI 均含零），且在把深度与数据量两轴解耦后（每个深度跑满同一组 6 个 $n$ 档，432 次运行）仍与深度和 $n$ 均无关。把（i）与（iii）合起来读：阈值对符号系统不变，不是因为模型掌握了跨符号的结构抽象，而是因为它记住了 token 串到类型转移的映射。CSH 的弱版本（阈值对符号系统不变）与本文一致；强版本（约束源必须由人类感官建立）既未被本文支持，也未被本文反驳——本文给出的是一条它不预测的反证。

**限制.** 以下五条须与结论同时阅读。**一**、本文不能区分猜想 A（感官约束）与猜想 B（归纳偏置恰好匹配人类偏好）：两者在换表面语言下预测相同。§6 虽确立了解是符号特化的（与 Gan & Isola 的"特化者而非通才"一致），却不区分这一特化的来源。要在本文设置内区分需要一个签名表与类型结构可独立操纵的基质族，本文未构造。**二**、类型结构只是认知基底的代理而非它本身；只要还在使用"序列、二元关系、对象"这套形式，就已带入人类先验，因此预测 P2 需要一个非人类先验的形式系统。**三**、结果不可外推到真实语言模型的规模轴：本文模型约 1M 参数，阈值定义在**训练样本数**而非参数量上。这一边界有机制性理由而非仅是尺度谨慎——Gan & Isola（2026）表明预训练权重邻域内的解密度随模型规模单调上升，因此本文的阴性结果恰恰应是较小模型的属性，规模增大后模型可能开始学到可迁移的结构抽象。在更大模型上重做 §6.2 是一个方向明确、可证伪的后续实验。**四**、复杂度轴 null 对照的证据集中在 $n \le 6500$：扩展网格上 $\mathrm{acc} \ge 0.99$ 的格点占 191/216 = 88.4%，三档高 $n$ 只能读出"都学会了"。**五**、拉丁方复现做到 8 种子而未到 36；§6.3 剔天花板后只剩 3 个共同种子，是"未发现效应"而非"确认无效应"。16 与 36 种子的扩充仍是明确遗留的工作。

本文与 Gan & Isola（2026）在另一条轴上得到的结果同构。他们表明预训练权重邻域内的解是特化者而非通才，并把基准分数上的提升分解为"格式灌木丛"（表层，19.0%）与"推理灌木丛"（深层，12.3%）——看似的能力变化可能来自相对肤浅的差异。本文在符号轴上得到同一条要求：表层现象与结构内容必须分别测量，而测量的形式本身必须被检验。

综合起来：符号置换在本文检验的两条轴上都未产生可检出的代价，而这条阴性结果的成立条件是可以写下来执行的；同时，可获得的解是符号特化的，因此"符号无关紧要"并不等于"结构已被掌握"。在合成的、严格控制的尺度上，不仅需要能把这两者分离，还必须先把测量本身修对——否则分离出来的可能只是测量方式的镜像。

## 附录 C：与 Neural Thitches 的对照要点

| | 本文 | Gan & Isola (2026) |
|---|---|---|
| 变化的轴 | 训练样本数、关系结构复杂度 | 模型规模、预训练分布多样性 |

两文的互补关系：本文固定模型规模、变化样本与结构轴；Neural Thickets 固定任务、变化规模与预训练多样性轴。本文§7 限制三由此获得一个具体的可证伪后续：**在更大模型上重做深度扫描**——若解更稠密更多样，代价可能不再是深度平坦的。

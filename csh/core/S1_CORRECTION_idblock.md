# 纠正：surface_fix 的 "alien 更慢" 是 id 块位置的假象

日期：2026-10-05
影响：`实验包_20261005/01_S1修复结果_180runs.md` 的 §4–§5 结论

---

## 结论

`01_S1修复结果_180runs.md` 报告"7/15 配对显著，5 个涉及 alien，
alien 系统性慢于所有人类语言表面（阈值 5,659）"。

**该结论是 id 块位置混淆的产物，不能归因于符号身份。**

---

## 证据一：该设计的 id 块位置与表面完全共变

`surface_fix.py:55` 的 `build_shared_vocab()`：

```python
for si, n in enumerate(NAMES):        # zh=0, en=1, lisp=2, math=3, code=4, alien=5
    ...
    for t in sorted(toks):
        v.add("%d\x00%s" % (si, t))
```

id 块位置**恒等于**表面在 `NAMES` 中的下标。于是：

| 表面 | id 块 slot | 阈值 |
|---|---|---|
| zh | 0 | 4,143 |
| en | 1 | 4,146 |
| lisp | 2 | 4,401 |
| math | 3 | 4,667 |
| code | 4 | 4,882 |
| **alien** | **5** | **5,659** |

**Pearson r(slot, 阈值) = +0.9368** —— 阈值随 id 块位置单调上升。
表面身份与块位置在数据上不可分离。

## 证据二：控制实验证明 id 块位置本身就有巨大效应

`idblock_control.py`：固定**同一表面（en）**、同一数据、同一种子，
**只改变它的 id 块位置**：

| id 块 slot | n=4000 |
|---|---|
| 0 | 0.5858 |
| 1 | 0.3225 |
| 2 | 0.7258 |
| 3 | 0.9833 |
| 4 | 0.2467 |
| 5 | 0.4042 |

**极差 0.1675 – 1.0000。** 方差分解：between-slot 0.06414、
within-slot 0.06184，**比值 1.04**（与种子噪声同量级）。

机制：`torch.manual_seed(seed)` 后 `Solver(V)` 按固定顺序初始化
embedding。token 落在哪个 id 区间，决定它分到哪一行随机初始化。
**这是初始化运气，不是符号身份效应。**

`alien` 被固定放在第 5 块，它测到的所有"劣势"都与"第 5 块"不可分离。

## 证据三：配平 id 块位置后，全部配对不显著

`surface_fix2.py` 用 **6×6 循环拉丁方**（slot = (surface_index + seed) mod 6），
使每个表面在 6 个种子上恰好经历全部 6 个 id 区间各一次。180 runs，
零错误（`results/surface_fix2.jsonl`）：

| 表面 | 经历的 slot | 阈值 | 对总体配对差 |
|---|---|---|---|
| zh | 0–5 各一次 | 4,835 | −0.032 n.s. |
| en | 0–5 各一次 | 3,840 | +0.082 n.s. |
| lisp | 0–5 各一次 | 4,479 | +0.060 n.s. |
| math | 0–5 各一次 | 4,894 | −0.034 n.s. |
| code | 0–5 各一次 | 4,810 | −0.055 n.s. |
| **alien** | **0–5 各一次** | **4,767** | **−0.021 n.s.** |

- **Pearson r(表面下标, 阈值) = +0.3977**（共变设计中是 +0.9368）
- **15 个配对全部 n.s.**（共变设计中有 7 个显著）
- 几何均值 4,588，极差 1,054（23%），**CV(log) = 0.0110**

`alien` 不再是异常值：4,767，位于 `en`(3,840) 与 `math`(4,894) 之间。

## 对两份数据结论的合并读法

| | surface_fix（共变） | surface_fix2（拉丁方配平） |
|---|---|---|
| 退化配对 | 0 | 0 |
| CV(log) | 0.0141 | 0.0110 |
| 极差 | 33% | 23% |
| r(slot/surface, 阈值) | +0.9368 | +0.3977 |
| 显著配对数 | 7/15 | **0/15** |
| alien 判定 | 最慢，异常值 | 与其余表面不可区分 |

**两份数据对 S1 的判定一致（CV < 0.15，S1 成立），
但对 "alien 例外" 的判定相反。配平设计（surface_fix2）是正确读法。**

因此：

- **S1 成立**——两份数据都支持，且修复后不再是重言式。
- **"alien 系统性更慢" 不成立**——它是 id 块位置的假象。
  `01_S1修复结果_180runs.md` §4 的显著配对表与 §5 的
  "alien 是可测量的例外"结论应撤回。

## 对论文的净建议

1. `§6.1 S1` 的数字用 **surface_fix2**：CV(log)=0.0110，6 表面，0 退化配对，
   15 配对全 n.s.。
2. **不要**写入"alien 是符号身份的边界条件"——该效应已被控制实验排除。
3. `alien` 安慰剂臂**可以重新启用**：修复后它与 `zh` 不再逐位相同
   （拉丁方配平下 0/30 identical），具备了安慰剂臂所需的独立性。
   但仍需与 `zh` 做同 seed 配对检验才能宣称其"未偏离"。
4. **方法学发现五需改写**。原文写"若修复后 CV 越过 0.15 主结论会翻转"——
   更重要的是后半句：**修复本身若不做 id 位置配平，会引入一个与种子噪声
   同量级的伪效应**（控制实验：同一表面 0.1675–1.0000）。这是比"CV 可能翻转"
   更实际的教训。

# 附：S2 的第二个混淆（vocab 大小不匹配）

日期：2026-10-05 追加

## 发现

`03_S2置换检验结果.md` 的结论建立在两份数据上：

| 数据 | vocab 大小 | 表面 |
|---|---|---|
| `surface_fix.jsonl` | **169** | 6 个真实表面 |
| `surface_fix_null.jsonl` | **225** | relperm / entperm（slot 101、201） |

**两份数据的词表大小不同。** 而 `model.py:97` 是：

```python
torch.manual_seed(seed)
model = Solver(len(vocab))      # 参数量与初始化都由 len(vocab) 决定
```

`Solver(225)` 与 `Solver(169)` 的 embedding 形状不同（225 vs 169 行），
因此**参数总量、随机初始化、以及 head 与 embedding 的绑定形状都不同**。

所以 `null 阈值 − real 阈值` 这个配对差里，混进了**模型规模差异**，
不只是符号置换的效应。

## 影响方向

- S2 是个**阴性结论**（14/14 p > 0.10，未检出差异）。
- 规模差异会引入额外的组间方差，**降低检出功效**——因此这个混淆
  使 S2 的结论**偏保守**，不会造成假阳性。
- 但它使"null 与真实表面不可区分"这句话**不够干净**：读者无法知道
  是"置换无代价"还是"规模差异掩盖了代价"。

## 建议的修正

让 null 臂与真实表面**共用同一个词表大小**：

1. 建**一个**共享词表，包含全部 8 个臂（6 真实 + 2 null）的 token，
   各占一段互不相交的 id 区间。
2. 用**同一个拉丁方**配平这 8 个臂的 id 块位置
   （`slot = (arm_index + seed) mod 8`，要求种子数 ≥ 8）。
3. 重跑 S2 的置换检验。

这样 vocab 大小对全部 8 臂恒定（唯一变量是符号身份），
且 id 块位置被配平。预期代价：约 8 臂 × 5 n × 8 种子 = 320 runs。

## 与 §6.4 的关系

`03` 提出把 S2 从"集合包含"升级为"配对差 + 置换检验"，方向正确。
但配对必须是**同规模、同 id 配平**下的配对，否则升级后的检验
仍在测一个混合量。这一点应在论文里写明。

## 三个连续结论

### 结论一：原 S1 部分是重言式（已证实）

`build_vocab` 按首次出现顺序分配 id；因每条事实恰 5 token、query 模板
固定，角色结构在所有表面间相同，故 zh/math/alien 得到**逐 token 相同**
的数值输入：

```
zh vs math   : 30/30 id-sequences IDENTICAL
zh vs alien  : 30/30 id-sequences IDENTICAL
en vs relperm: 30/30 id-sequences IDENTICAL
权重逐位相同 : max |weight diff| = 0.000e+00
```

36 种子下 6 个"表面"只产生 4 个独立数字。故 `alien` 安慰剂臂在实现上
就是 `zh`（其检验不可能触发），§6.2 的 S2 是一个数与自身的比较。

### 结论二：token 身份在本任务中不携带信息（已证实）

把 token 身份完全移除（只留槽位+关系序号+实体序号的规范 id）：

```
A. identity removed (canonical)  acc=1.0000
B. identity removed, permuted    acc=1.0000
```

两者都达 1.000。符号身份可被完全删除而任务仍可求解 —— 这解释了
原设计为何退化：只要任务是"按位置给出的关系序号沿链查找实体"，
符号身份在编码阶段就必然被消除。

### 结论三：修复必须配平 id 位置（已证实，且已修正）

第一次修复把 id 按**表面顺序**分块，结果阈值呈完全单调排序
（zh 4143 < en 4146 < lisp 4401 < math 4667 < code 4882 < alien 5659），
与 id 块位置同序。

控制实验：固定**同一表面（en）**、同一数据、同一种子，只改 id 块位置：

| id 块 slot | n=4000 | n=6500 |
|---|---|---|
| 0 | 0.5858 | 1.0000 |
| 1 | 0.3225 | 0.7358 |
| 2 | 0.7258 | 0.7700 |
| 3 | 0.9833 | 1.0000 |
| 4 | 0.2467 | 0.7208 |
| 5 | 0.4042 | 0.9358 |

n=4000 极差 **0.1675–1.0000**。方差分解：between-slot 0.06414、
within-slot 0.06184，**比值 1.04**（与种子噪声同量级）。

机制：`torch.manual_seed(seed)` 后 `Solver(V)` 按固定顺序初始化
embedding；token 落在哪个 id 区间决定它分到哪一行随机初始化。
**这是初始化运气，不是符号身份效应。**

---

## 正确设计：6×6 循环拉丁方

    seed s, surface i  ->  id 块 slot = (i + s) mod 6

每个表面在 6 个种子上恰好经历全部 6 个 id 区间各一次，slot 完全配平，
surface 主效应与 slot 主效应可分离。

## 对论文的净影响

**主张不变，证据升级。**

- 原文："6 个表面共享阈值，CV=0.009" —— 其中部分是重复计数。
- 修正后："6 个表面共享阈值，CV=0.0110，且配对差全部不显著" —— 
  这次是用**真正相互独立、id 分配已配平**的表面测出的。

原结论的强度**未被削弱**，反而因为通过了更严格的检验而更可靠。

`alien` 安慰剂臂的说法（它当前实现等同于 `zh`；修复后已不等同，
可重新作为安慰剂臂使用）。

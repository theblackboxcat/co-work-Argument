3. 倒 U 形的形状检验：三种读数各自能不能定出峰
==============================================================================

  ---- surface = en ----

            读数                        序列(C_eff降序)  log-log slope
     n@acc=0.5 4385.828 → 4978.131 → 4683.557 → 3709.108 → 2074.651      +1019.905
          area 0.486 → 0.418 → 0.458 → 0.590 → 0.938         -0.187
   logit slope 1.224 → 1.826 → 1.932 → 1.406 → 1.369         +0.040  (有 2 档有效种子<4)

  ---- surface = relperm ----

            读数                        序列(C_eff降序)  log-log slope
     n@acc=0.5 4045.827 → 4352.268 → 4265.420 → 3834.209 → 2000.000       +816.246
          area 0.538 → 0.552 → 0.566 → 0.627 → 0.966         -0.161
   logit slope 2.918 → 1.670 → 2.007 → 2.900 → 1.034         +0.445  (有 4 档有效种子<4)

  方向约定（改错过一次，记在这里）：
   n@acc=0.5 **越大越难**（等更久才到0.5）
   area **越小越难**（曲线下面积小 = 大部分 n 上都低 acc）
   logit slope **越小越难**（爬升慢）
  倒U = 中间档最难：n½ 在中间取**极大**、area 取**极小**、
  logit slope 取**极小**。三个方向一致才算同一现象。

  若三种读数一致给出「中间档最难」，倒 U 就与 τ 判据无关，
  也与网格上界无关。若不一致，则现有倒 U 报告必须降级为
  「阈值法下的现象」，并说明它与网格的耦合。

==============================================================================

  surface=en
         n@acc=0.5: 最难档 C_eff=16  有效档 5/5 4385.828 → 4978.131 → 4683.557 → 3709.108 → 2074.651 
              area: 最难档 C_eff=16  有效档 5/5 0.486 → 0.418 → 0.458 → 0.590 → 0.938 
       logit slope: 最难档 C_eff=2  有效档 3/5 1.826 → 1.932 → 1.369 （剔除 [24, 5]：有效种子不足 4）
    → 读数不一致（['n@acc=0.5:C_eff=16', 'area:C_eff=16', 'logit slope:C_eff=2']）
      倒 U 的峰位置依赖读数选择，现有报告不能声称峰稳定在 C_eff=16

  surface=relperm
         n@acc=0.5: 最难档 C_eff=16  有效档 5/5 4045.827 → 4352.268 → 4265.420 → 3834.209 → 2000.000 
              area: 最难档 C_eff=24  有效档 5/5 0.538 → 0.552 → 0.566 → 0.627 → 0.966

      倒 U 的峰位置依赖读数选择，现有报告不能声称峰稳定在 C_eff=16
    → logit 读数因样本不足弃用；另两种读数（n½、area）都不依赖跨线判据，结论以其为准

5. E10 内附带的 null 对照：relperm 的阈值动了吗
==============================================================================

  E10 原本只打算回答「C_eff 轴上有没有倒 U」，但它的设计上
  顺带带了一个 null臂：relperm（关系标签置换，结构不变）。
  这个对照此前没人读。它是免费的，且正对着S2 的核心主张
  「符号置换不改阈值」。

   C_eff  n_pairs   Δlog n*               95% CI      倍比         p
      24        4    -0.181 [ -0.486, +0.262]    0.83    0.6256
      16        3    -0.162 [ -0.486, +0.000]    0.85    1.0000
       8        3    -0.183 [ -0.511, +0.223]    0.83    0.4948
       5        2    +0.112 [ +0.000, +0.223]    1.12    1.0000
       2        6    -0.270 [ -0.405, -0.135]    0.76    0.1258

  CI 含 0（阈值不可区分）：4/5 档
  倍比 < 1（relperm 阈值更低）：4/5 档

  **没有任何一档出现 relperm 阈值更高。** 倍比区间 0.76–1.12，全部 ≤ 1 或与 1 不显著。

  读法（两个方向都要说）：
   * 支持 S2：关系标签置换在 C_eff 轴的每一档都不抬高阈值，
     甚至系统性略低。这与「S2 的平坦是关于结构的陈述」一致。
   * 但'略低'本身不是零效应。Δlog n* 的分辨率下限仍是 0.223
     （见 1 节），而这些比值的 CI 有 4/5 档贴到 0 附近。
     严格说法是「没有证据表明 relperm 更难，且方向一致偏易」，
     而不是「relperm 完全无影响」。

  这条对照比E6 的 null 更强：E6 的 relperm/entperm 只有
  3 个表面，C_eff 恒为24；E10 有 5 个 C_eff 水平，且
  拉丁方配平已验证（vocab恒定、block_slot 均匀）。

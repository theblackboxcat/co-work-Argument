C. 把 penalty 放回 depth 全景：它是否随 depth 增长

  说明：各 depth 的 n 网格不同，所以这里用 depth 的序号
  回归斜率作为「随 depth 增不减」的读数，不解释为 log-log弹性。
        cell  slope/depth               95% CI      verdict
          TU       +0.015 [  -0.059,  +0.089]          不明确

  C 段读法：

  **Thighovl 的 penalty 恒等于 0（CI 宽度 < 0.01），这是本节最强的
  正结果，不是对照组的沉默。** 它与typed 基质的签名表重叠 5/6，
  只改一个实体，泛化损失在三个 depth 上都测不出来。这说明模型
  不是在背6 条具体的关系→类型查表：查表里改一条，它照样能
  从其余约束推出那一行。

  **penalty 随签名表改动量单调上升**（overlap 5/6→2/6→0/6：
  0.00 → 0.25~0.34 → 0.41~0.58）。这给「签名表是被学到的东西」
  一个内部的剂量-反应关系，比「变换 vs 不变换」的二元对比强得多。

  **penalty 不随 depth 明显上升**（TU、Tlowovl 的斜率 CI 都跨 0）。
  这一条对论文是个提醒，不能顺着 §7.3 的既有说法直接用：
  各 depth 的 n 网格不同（d3:2000–6500, d4:5000–11000,
  d5:11000–20000），depth 与训练量在这份数据里是纠缠的，
  CI 跨 0 可能来自这个混淆而不是「penalty 真的与 depth 无关」。
  要拆开必须做depth × n 的交叉网格——这是**唯一值得真跑**的
  追加实验（见09_算力分级.md 的 T1）。

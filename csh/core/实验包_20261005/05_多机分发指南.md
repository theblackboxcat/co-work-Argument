## 1. 怎么分发

### 最省事：用自包含分发包

`分发包_自包含.zip`（105 KB）已包含全部依赖：

```
CSH_slices/
  model.py  substrate2.py  surfaces.py  transfer.py   ← 原始代码
  substrate.py  analysis.py
  e10_ushape.py  e8_scale.py  arm_k_null.py
  decouple_e4.py  xarch.py  e9_ollama.py
  make_slices.py  run_slice.py  merge_slices.py
  s2_permutation.py
  slices/            60 个 spec + 5 个 manifest
```

1. 把这个 zip 拷到目标机器
2. 解压
3. `pip install torch numpy`（若未装）
4. 跳到下面步骤 3

### 步骤 1：生成切片（已生成，分发包内已有）

```bash
C:/Python314/python.exe make_slices.py
```

产出 `slices/` 目录：60 个 spec 文件 + 5 个 MANIFEST。

### 步骤 2：拷贝到目标机器

每台机器需要：

```
package/                     整个目录（原始代码）
package/实验包_20261005/      分发脚本
package/实验包_20261005/slices/   它负责的那几片
```

**不需要拷贝 `results/`**——spec 里是完整参数，不依赖本机状态。

### 步骤 3：在目标机器上跑

```bash
cd package/实验包_20261005
C:/Python314/python.exe run_slice.py \
    --spec slices/E10_slice03.json \
    --out results/E10_slice03.jsonl \
    --workers 4
```

- `--workers` 按机器核数/2 给（每个 worker 内部 torch 已设 3 线程）
- 中途 kill 后重跑同一条命令会**自动跳过已完成的**
- 输出文件名必须带slice 名，避免互相覆盖

### 步骤 4：把结果文件传回来

传 `results/E10_slice03.jsonl` 即可。

### 步骤 5：合并

```bash
C:/Python314/python.exe merge_slices.py --exp E10 \
    --inputs "results/E10_slice*.jsonl" --verify
```

`--verify` 会报出缺哪些格点。若有缺失，重新跑 `make_slices.py --experiment E10`
——它会读现有结果自动剔除已完成的，只切出缺的。

去掉 `--verify` 才真正写合并文件。

## 2. 三条安全保证

### 不重跑

`make_slices.py` 扫过 `results/*.jsonl` 全部记录，把已完成的格点从待办里剔除。
分片后有断言：片内无重复、片间无重叠、并集 == 待办、且不与已完成集相交。

**这里踩过一次坑**：我最初用 `"C_eff3" in r` 判别E10 已完成，
但论文原有的 `final.jsonl` 臂 K 记录也带 `C_eff3` 字段，
结果 done 被误判成 1440（上限只有 300），**240 个真任务会被静默漏跑**。

修法两条：
1. 判别式改用 `arm` 字段（`arm == "E10"`）
2. 加硬保险：`done > 网格上限` 直接 `SystemExit` 中止

**你在别处写类似脚本时务必记住：判别"这个格点是否做过"要用实验专属标识，
不要用数据里可能普遍存在的字段。**

### 不互相覆盖

- 每个 slice 写自己的文件，文件名带 slice 名
- 合并时按业务键去重，先到的为准
- 冲突（同一格点两条不同 acc）会**报出来但不自动丢弃**，供人工判断

### 不拖后腿

按 cost = `OVERHEAD + 0.019 × n_train`（架构系数另乘）做 LPT 装箱，
不是按条数平分。实测每片代价差异 < 1%。


```bash

```

E8 本机要42 小时（实测并发时单 run 从105 s 涨到 235 s），
**强烈建议不要在本机跑 E8**。

## 5. 文件清单

| 文件 | 作用 |
|---|---|
| `make_slices.py` | 切分（读现有结果 → 剔除已完成 → LPT 装箱 → 写 spec） |
| `run_slice.py` | worker（认得全部 5 个实验，支持续跑） |
| `merge_slices.py` | 合并（去重 + 冲突报告 + 网格覆盖校验） |
| `slices/*.json` | 60 个 spec |
| `slices/*_MANIFEST.json` | 每实验的切片清单与代价 |

分片是**声明式**的：重跑 `make_slices.py` 会根据当前 `results/` 重新计算，
所以中途想改切片数（比如从 12 改成 24）直接改 `--n-slices` 重跑即可。

| 4 | en / relperm / entperm | 6 / 6 / 6 | 0 | 4724 / 4758 / 5093 |

9 个 (mult, surface) 组合全部 6/6 可测，删失解除。

### 2.2 但88.4% 的扩展格点撞到天花板

扩展网格（n = 8500/11000/14000）上 acc ≥ 0.99 的比例是 **191/216 = 88.4%**：

| n | 饱和比例 |
|---|---|
| 8500 | 49/54 = 90.7% |
| 11000 | 53/54 = 98.1% |
| 14000 | 54/54 = 100% |

这意味着补上界**买到了阈值可测性，但失去了分辨率**——8500 以上的三档
基本只能读出"都学会了"。这是设计上的取舍，不是缺陷，但必须在论文里
写明：E6X 的信息量集中在 n ≤ 6500。

### 2.3 mult 主效应：无一致方向

不是欠拟合**；但它把 mult=4/en 的 acc 均值从 ~1.00 压到 0.86，
制造出一条假「平台」。这类种子不应被当无效样本剔除（那是按结果选样本），
而应作为 mult 效应的方差来源写进限制。

### 2.4 null 臂在复杂度轴上同样不可区分

这直接回答论文 §8 边界四：「臂 K 未在各复杂度水平重跑 null 对照」。

在 n ≤ 6500 的 15 个 (mult, n) 组合上，null 与 en 的配对差全部 p > 0.05，
最小的一个是 mult=2 / n=4000 的 entperm（+0.1325, p = 0.060）。
n ≥ 8500 的组合因天花板效应配对差恒为 0，无信息量。

**所以 K-A 的平坦与 S2 的平坦是同一件事**：符号置换在两个轴（表面轴、
复杂度轴）上都不产生可检出的代价。

### 2.5 论文要改什么

§8 边界四原文：

> 臂 K 未在各复杂度水平重跑 null 对照。因此 K-A 的结论强度低于臂 S 的
> S1/S2：我们无法排除复杂度臂上同样存在 null 效应。

改为：

> 臂 K 已在 mult ∈ {2,3,4} × n ∈ {6500, 8500, 11000, 14000} 上补齐
> null 对照（216 runs）。在 n ≤ 6500 的 15 个 (mult, n) 组合上，两个
> 置换臂与 `en` 的逐seed 配对差全部 p > 0.05。**复杂度轴上的平坦与
> 表面轴上的 S2 是同一件事：符号置换在两个轴上都不产生可检出的代价。**

但要补一句限制：扩展网格 88.4% 的格点acc ≥ 0.99，**n ≥ 8500 的三档
只能读出"都学会了"**，因此该结论的证据集中在 n ≤ 6500。

## 3. DPX：penalty 与 depth 无关，也与 n 无关——但有一个必须报告的天花板修正

### 3.1 纠缠拆开后的 TT 基线

```
depth     4000     5000     6500     8500    11000    14000
    3    0.6088   0.8750   0.9958   1.0000   1.0000   1.0000
    4    0.4629   0.8133   1.0000   1.0000   1.0000   1.0000
    5    0.3829   0.5108   0.7475   0.8421   0.9575   1.0000
```

无删失读数：n@0.5 = 4000 / 5000 / 5000；area = 0.9401 / 0.9160 / 0.7552。
**depth 越大确实越难**（area 单调下降）——这说明 depth 轴不是死的，
因此"penalty 不随 depth 变化"不能被解释为"depth 没起作用"。

### 3.2 一个假信号，和它的根因

第一遍算depth 斜率时，`Thighovl` 给出

```
d5 − d3 = +0.0120  CI=[+0.0016, +0.0210]  p=0.0923   → "随depth 上升"
```

CI 不含0 而 p > 0.05，两者矛盾。查逐 seed 配对差才发现根因：

```
Thighovl depth3, n=6500:  +0.0000 +0.0000 +0.0000 +0.0000 +0.0000 −0.0050
Thighovl depth3, n=8500:  +0.0000 +0.0000 +0.0000 +0.0000 +0.0000 +0.0000
Thighovl depth3, n=11000: +0.0000 ×6
```

**depth3 的 Thighovl 在 n ≥ 6500 上已经饱和**，配对差恒为 0。
这些 0 不是"没有差异"，是"两者都会了"。把它们计入均值，
斜率完全由depth5 那几个尚未饱和的格点驱动；而 bootstrap 百分位 CI
在大量 0 值下会偏窄，于是给出"不含 0"的假象。

TT 基线的饱和分布（饱和种子数/该格种子数）：

```
depth     4000     5000     6500     8500    11000    14000
    3      2/6     4/6     5/6     6/6     6/6     6/6
    4      0/6     3/6     6/6     6/6     6/6     6/6
    5      1/6     1/6     3/6     4/6     5/6     6/6
```

**depth3 在 n=4000 就已有 2/6 饱和，depth5 到 n=14000 才全饱和**——
两端的饱和程度差很多，直接比平均值是不公平的。

### 3.3 剔除天花板后的结论

剔除TT 与cell 都 acc ≥ 0.99 的格点（有效格点 18 → 10）：

| cell | 口径 | d5 − d3 | 95% CI | p | 共同种子 | 判定 |
|---|---|---|---|---|---|---|
| TU | 全量 | −0.0278 | [−0.1369, +0.0889] | 0.685 | 6 | 与 depth 无关 |
| TU | 剔天花板 | −0.0196 | [−0.2610, +0.3425] | 1.000 | 3 | 与 depth 无关 |
| **Thighovl** | 全量 | +0.0120 | [+0.0016, +0.0210] | 0.092 | 6 | *假信号* |
| **Thighovl** | **剔天花板** | +0.0256 | [−0.0233, +0.0588] | 0.495 | 3 | **与 depth 无关** |
| Tlowovl | 全量 | −0.0246 | [−0.1478, +0.1228] | 0.810 | 6 | 与 depth 无关 |
| Tlowovl | 剔天花板 | −0.0556 | [−0.4063, +0.4338] | 1.000 | 3 | 与 depth 无关 |

**剔天花板后三个变换一致：penalty 与 depth 无关。**

n 方向（同一 depth 内跨 n 档），全量口径：

| cell | Δ(n=4000 → 14000) | 95% CI | p | 判定 |
|---|---|---|---|---|
| TU | +0.0186 | [−0.0361, +0.0859] | 0.712 | 与 n 无关 |
| Thighovl | +0.0031 | [−0.0106, +0.0203] | 0.809 | 与 n 无关 |
| Tlowovl | +0.0192 | [−0.0585, +0.0993] | 0.780 | 与 n 无关 |

penalty 的 n 斜率在剔天花板后无法计算（末档 n=14000 全部饱和，
只剩 n=4000/5000 两档，不构成斜率），这一点必须在论文里说明，
不能拿"全量口径与 n 无关"冒充覆盖全网格的结论。

### 3.4 论文要改什么

DPX 原本要回答的是：「E4 里 penalty 不随 depth 上升，是真的与 depth 无关，
还是 depth 与 n 完全纠缠造成的假象？」

> **答：是"与 depth 无关"，纠缠已拆开。**
>
> 每个 depth 都跑满同一组 6 个 n（4000/5000/6500/8500/11000/14000）
> × 4 个变换 × 6 种子，共 432 runs。TT 基线本身随 depth 变难
> （area 0.9401 → 0.9160 → 0.7552），但三个变换的逐 seed 配对
> penalty 在 d5−d3 上均不显著（剔天花板口径：TU −0.0196[
> −0.261, +0.343] p=1.00；Thighovl +0.0256 [−0.023, +0.059] p=0.49；
> Tlowovl −0.0556 [−0.406, +0.434] p=1.00）。
>
> **方法学限定：** 该比较必须在剔除天花板格点（TT 与变换均 acc ≥ 0.99）
> 后进行。全量口径下 `Thighovl` 会给出 d5−d3 = +0.0120，
> CI = [+0.0016, +0.0210] 不含 0，看上去"随 depth 上升"——
> 但那是因为 depth3 在 n ≥ 6500 上已饱和，配对差恒为 0，
> 斜率完全由 depth5 的少数未饱和格点驱动，且 bootstrap 百分位 CI
> 在大量 0 值下偏窄（同一数据 p = 0.0923）。**"CI 不含 0 但 p > 0.05"
> 这个矛盾形态本身就是天花板污染的指纹。**

## 4. 三条结论与其代价

### 4.1 现在可以说的

1. **S2 是稳健阴性**：符号置换在表面轴上零代价，且该结论对配对方式、
   判据阈值、词表规模三项都不敏感。
2. **平坦是关于结构的**：符号置换在复杂度轴（mult∈{2,3,4}）上同样
   零代价，15 个 (mult, n) 组合全部 p > 0.05。S2 与 K-A 是同一件事。
3. **penalty 与 depth 无关**：纠缠拆开后，三个变换的 d5−d3 全部不显著，
   且这个结论在两种口径下都成立（除 Thighovl 的全量口径，那里是假信号）。

### 4.2 三条限制，必须一起写

1. **E6X 的天花板**：扩展网格 88.4% 的 acc ≥ 0.99，n ≥ 8500 的三档
   只能读出"都学会了"。K-A 的 null 结论证据集中在 n ≤ 6500。
2. **DPX 的 n 斜率覆盖不全**：剔天花板后只剩 n=4000/5000 两档，
   不足以估 n 斜率。"penalty 与 n 无关"只在全量口径下成立，
   而全量口径含饱和格点。
3. **DPX 剔天花板后只剩 3 个共同种子**：n=4000/5000 两档上未饱和的
   种子只有 3/6。功效不足，结论是"未发现效应"而非"确认无效应"。

### 4.3 本轮新增的可复用方法学

**"CI 不含 0 但 p > 0.05" 是天花板污染的指纹。**
两个统计量用不同的信息：bootstrap 百分位 CI 在配对差大量为 0 时会偏窄，
符号翻转 p 在 0 值多时功效不足。当配对差来自"两者都会了"而非
"两者没差别"时，前者会给出假显著、后者给出正确的阴性。
**两者不一致时，正确的诊断不是挑一个信，而是回头查配对差里有几个 0。**

这个形态与 `03_S2置换检验结果.md` 记录的另一处坑同源：
"看起来更严格的 z 统计量，因分母趋零给出完全误导的显著度"。
两处的共同点是——**统计量的形式会独立于数据改变结论**。

| P2 | S2L 增加种子到 16 | 现有 8 seeds 恰好配平 8 表面。加到 16 可把 bootstrap CI 收窄约 √2 倍 |
| P2 | Thighovl 的低 n 加密 | Thighovl 的 penalty 恒在 ±0.03 内，是三个变换里信号最弱的，可能需要更细的 n 网格才能看出随 depth 的漂移 |
| P3 | mult=4 的「晚熟种子」现象 | 见下|

### 关于 mult=4 的晚熟种子

初查时我以为`mult=4 / en / seed1` 是训练失败（n=2000 到 11000 的 acc 恒在
0.075–0.200），**这个判断是错的**：该种子在 n=14000 达到 acc = 1.000。
它不是没学会，是**比同组其他种子晚一档**：

```
mult=4, en, 逐 seed acc
seed       2000    3000    4000    5000    6500    8500   11000   14000
  0     0.060   0.120   0.235   1.000   1.000   1.000   1.000   1.000
  1     0.080   0.075   0.160   0.168   0.188   0.168   0.200   1.000   <- 晚熟
  2     0.072   0.138   1.000   1.000   1.000   1.000   1.000   1.000
  3     0.072   0.138   0.282   0.950   1.000   1.000   1.000   1.000
  4     0.085   0.083   0.833   1.000   1.000   1.000   1.000   1.000
  5     0.030   0.145   0.945   1.000   1.000   1.000   1.000   1.000
```

它把 mult=4/en 在 n=6500/8500/11000 的均值从~1.00 拉到 0.86/0.86/0.87，
从而在 acc 均值表上造出 mult=4/en 的一条「平台」。查`steps` 字段，
全部 18 个格点的 steps 集合完全相同（{62, 93, 125, 156, 203, 265, 343, 437}，
只随 n 变），**说明训练步数正常，不是欠拟合**。

`relperm` 的 seed1 与 seed3 也是晚熟（0.19→0.33→0.955）。
即晚熟不是孤例，而是 mult=4 这一档的特征——关系种类数更高时，
到达阈值所需的 n 分布更宽。这本身是个可报告的现象，但**不应写成
"某些种子无效"**，也不应把该种子从统计里剔除（剔掉就等于按结果选样本）。

## 3. 216 / 219 细挖（JSON · 非经典渗透）

### 3.1 seed216 — **NOT permeability**；满 ceiling 后仍 C1 败

- `C4pp.pass=true`；`i_directional=T`；`iii_specific=T`；`0_codebook_valid=T`（held-out bal_acc **0.856** ≥0.75）。  
- `sparse.dwf=0.674`，`every.dwf=0.285` ≤ 0.5×sparse → 特异性过。  
- **唯一失败**：**C1** — margin **0.0979** < thr **0.1137**；abs **0.0124** < thr **0.0373**。  
- `epochs_ran=1600`（early_stop 未触发至 ceiling）。  
- 解读：写通道与特异性在本籽成立，但相对 memoryless 的回报边际/绝对回报未过尺子 → **效率/回报轴**残差，**不是** write-ok/hold-fail 模式。

### 3.2 seed219 — **NOT classic perm**；C1 败 + codebook 子句败（iii 却过）

- `i_directional=T`；`iii_specific=T`（`every.dwf=0.277` ≤ 0.5×`sparse.dwf=0.622`）；`ii_valuable_drop=T`。  
- **`0_codebook_valid=false`**：`codebook_heldout_bal_acc=0.699` < **0.75** → 整条 `C4pp.pass=false`（尽管 i∧iii 均为 T）。  
- 同时 **C1** 败：margin 0.157（过 margin 阈）但 abs **−0.0099** < 0.0373。  
- `epochs_ran=1600`。  
- 解读：**不是** `i∧¬iii` 渗透性模式；C4″ 假来自 **码本 held-out**，外加 C1 绝对回报。日志行 `C4pp=False i=True iii=True perm=False` 与 JSON 一致。

### 3.3 混杂 caveat（仍不推翻 Path B）

失败 5 籽中 2 籽（216/219）**不是**渗透性模式 → 存在 **失败模式混杂**。按计划：Path B 只要求失败籽中 **≥半数** 为 `i∧¬iii`（3/5），故机械仍判 B；报告必须显式写出混杂，**禁止**把全失败写成单一 hold-fail 叙事，也**禁止**据此削弱尺子或改判不定（不定需「不以渗透性为主」）。

## 1. 诊断协议（预注册）

### 1.1 对象

- **VOID 籽**（历史 C2-leak 超阈）：`{23, 24, 27, 28, 32, 36, 38, 46}`
- **非 VOID 对照**（同玩具 N=4）：`{16, 18, 20, 22, 25, 29, 33, 40, 43, 47}`（覆盖低/中/近阈）

### 1.2 度量（与验收同构）

- 环境：`N=4`，`T=200`，`K∈[30,70]`，`window=5`，`n_eps=12`（与 S1e/S1f2 `acceptance_per_seed` 一致）
- 函数：`obs_window_decode_acc`（obs-only；agent **不影响** obs，用固定 memoryless 即可）
- 历史单点探针：`probe_seed = science_seed + 10007`（复现归档值）
- **独立样本**：每籽 `n_rep=5`，探针种子  
  `probe_i = science_seed + 10007 + i * 100003`，`i=0..4`  
  （`i=0` ≡ 历史探针，便于对齐）

### 1.3 判决（计算前写死）

| 观察 | 结论 | 动作 |
|------|------|------|
| 籽内 SD（5 点样本标准差）**大**（经验：多数籽 SD≳0.03，或均值 SE 使越过 0.35 线不稳定） | **测量噪声主导** | 在调参籽 100–103 上标定更大 `n_rep`（或提高 `n_eps`），使**均值标准误 SE&lt;0.02**；预注册该样本量 |
| 籽内均值**稳定高于** 0.35 且 SD 小 | **生成器真泄漏** | 查 goal 序列 vs 时间/K（cue 后窗残留）；必要时新世界版本（本回合只报告，不改世界） |
| 混合 | 两者都记 | 预筛仍用下方裕度协议 |

**禁**：削弱 `C2_leak_max=0.35`；缩 VOID 分母；把噪声 VOID 改判为历史 PASS。

## 2. 预筛协议（新籽段 · 训练前）

- 起始籽：**≥200**，升序扫描
- 每籽用**诊断标定后的样本量**算 `leak_mean`
- 接受线：**`leak_mean ≤ 0.30`**（相对 VOID 线 0.35 的 **0.05 裕度**）
- 取**前 8** 个过线籽 → 冻结 `frozen/clean_seeds_Dx2.json` + sha256
- 验收 VOID 规则与 **denom=8** **不变**（后续 S1g 若开，仍 8 籽分母）

调参仅允许 **100–103**；**禁止**在科学 VOID 列表或 ≥200 预筛池上调阈。

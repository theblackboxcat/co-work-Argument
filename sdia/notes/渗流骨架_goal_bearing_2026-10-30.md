## 0. 本注要解决的一个问题

渗流类比在这条线上反复被提起，但一直停在「听起来像」。本注做三件事：

1. 把类比**限定**在临界骨架（序参量／阈值／关联长度），显式禁止数值平移；
2. 用**已有归档**检查这个类比到底有没有可对应的量——结论是：**有一个量对得上，另一个量在本归档里退化**；
3. 据此把「下一实验」从三条模糊候选，收敛成**一条可跑、两条应先杀**。

## 1. 一句硬 claim（可进预注册抬头，不可写成已证定理）

> 涌现式「目标可承载」与格子渗流共享的是**临界骨架**——序参量、连通性阈值、关联长度发散——而不是同一套数值 \(p_c\)。

映射表（表述用，非同构声明）：

| 渗流对象 | 协议对象（SDIA / gated write） |
|----------|-------------------------------|
| 格点 / site | 可被写入的门控通道单元（GRU 隐维上可「钉扎」的子空间；或指定寄存器槽） |
| 键 / bond | 世界回报与线索之间的**协变边**（world-return covariance 允许 cue→state 的信用通路） |
| 占据概率 \(p\) | 「开放且可写」通道占比：稀疏 cue 下仍能定向写入的有效门分数（非字面 dropout 率） |
| 巨连通簇（序参量） | **可解码且可保持**的目标状态：稀疏 cue 下 decode↑ ∧ 连续 cue 下不渗透塌缩（C2/C3 ∧ C4″(iii) ∧ C6） |
| 缺陷 / 空位 | leak 污染、VOID 籽、无协变边、无门控 cell（tanh-RNN 档） |

**一句话**：要逼近的不是「等于 2D site \(p_c\approx0.5927\)」，而是——当协变边＋门控位点的**有效占据**跨过**你们尺子上的连通阈值**时，目标态从碎片写入跃迁为可跨时间的寄存器。

非神创论约束不变：禁止设计者写入目标内容；目标只许世界／同伴来源。门控是**结构先验档**（S1g L2-self），不是「自己长出门」的发现宣称。

## 2. 拿归档对一遍：哪一条对得上，哪一条退化

### 2.1 对得上的那一条：C4″ 的「定向 ∧ 特异性」确实呈两段式

E2（`E2_s2c_learnable`，Dx2 干净 8 籽，denom=8 未缩，VOID=0）的 C4″ 拆开看：

| 子句 | 含义（近临界读法） | 8 籽结果 |
|------|-------------------|----------|
| `i_directional` | 稀疏 cue 下确实能定向写入（**局部簇已成形**） | **8/8 全过** |
| `ii_valuable_drop` | 对侧钉扎使价值下降（定向是功能性的，不是几何巧合） | **8/8 全过** |
| `iii_specific` | 连续 cue 下不被写通道覆盖（**全局 hold 贯通**） | **3/8**（200 / 216 / 219） |
| C6 撤除保持 | 撤除后仍保持 | 5/8 |
| C1 回报 | 相对 memless 的绝对/相对过线 | 5/8 |

**这就是草案说的「局部簇已成、全局 hold 未贯通」——现在它有逐籽数字了，不再只是读法。**

更关键的一处：`every.dwf / sparse.dwf` 这个比值（预注册阈值 0.5，`every_max_frac_of_sparse`）在 8 籽上不是二值，而是一条**跨越阈值的连续量**：

```
0.444  0.461  0.490 | 0.524  0.593 | 0.956  0.978  1.013
        ↑ 过线 3 籽        ↑ 最近失手（超线 4.8%）
```

- 阈值 0.5 把 8 籽切成 **3/5**，最近的一籽只超线 0.024；
- 比值均值 0.6825，sd 0.2528（n=8，SE 0.089，95% CI 半宽 0.175）——**CI 宽到可以横跨整条阈值**；
- 分布看起来是**两簇**（≈0.44–0.52 与 ≈0.96–1.01），中间只有一个 0.593 过渡籽。

**诚实的读法**：这条量确实是连续的、确实被冻结阈值切在中间、确实没饱和——这支持「把它当序参量候选」；但 8 个籽的散布是**种子噪声**，不是扫描轴，所以**不能**读成相图，**不能**读成 \(p_c\) 估计。它只说明：**尺子没饱和，切点没落在悬崖上，值得做一次真扫描。**

### 2.2 退化的那一条：缺陷（VOID）维度在本归档里没有方差

E2 的 leak 探针（`n_eps=12`、`n_rep=5`、N_goals=2、chance=0.5、VOID 线 = `A_empirical+0.10` = **0.6**；Dx2 遗产线 0.35 属 N=4 标定，未放宽）：

| 项 | 值 |
|----|----|
| 8 籽 `leak_mean_G` | **全部 0.5**（`samples` 五次全 0.5，`sd=0.0`，`se=0.0`） |
| VOID 籽数 | **0/8** |
| 分母 | **8**，未缩 |

也就是说：**在这个归档里，「缺陷密度」这一维恒定在 chance，没有可用的变异**。后果写在 `04_P2_void_prescreen.md`：Exp-P2（VOID 率–通过 相图）**以现有归档不可识别**，必须先杀或先改设计，不能靠它推进。

### 2.3 一处必须写明的混杂

三个「特异性过线」的籽是 200 / 216 / 219，但 **216 与 219 的 C1（回报）不过**（216 C1 margin 不足、219 G_ret 为负 −0.0099）。**特异性与功能回报不共变**：唯一同时过 C1 与 iii 的只有 seed 200，这正是 E2 组门 1/8 的来源。

所以「近临界」这句话必须带这个尾巴：**簇内特异性出现 ≠ 功能贯通**；把 3/8 说成「接近过线」会抹掉这层。

## 3. 禁止宣称（与 `02_forbid_addendum.md` 同步落库）

| 禁止 | 理由 |
|------|------|
| 「我们的门控临界 ≈ 2D site 59.27% / bond 50% / 3D …」 | 普适类不同；晶格、邻域、占据定义皆非同构；**骨架同构 ≠ 数值同构** |
| 「E2 1/8 或 E2b 3/8 = 已测得 \(p_c\)」 | 那是固定预算／固定尺子下的组门结果，不是占据相图上的临界点估计 |
| 「8 籽 ratio 跨 0.44–1.01 所以有临界」 | 种子噪声 ≠ 扫描轴；n=8 的 CI 半宽 0.175，横跨阈值 |
| write-ok/hold-fail = 跨预算定理 /「GRU 原理不能 hold」 | E2b 已明令禁止升格；216/219 非渗透混杂 |
| 系统发现 / 无先验 / 自己长出门 / 开 S3 | S1g 落通用门控档；E2 FAIL；S3 CLOSED |
| 进化不可达 / RNN 原理不可达 | 无预算扫描；RNN 未调参 |
| 削弱 C4″ 或 leak VOID 线以「凑临界」 | 尺子先于故事 |
| 把知音交互感／「懂这个人」写成已由渗流证明 | 升维–交互感仍是草案假说 |

**允许说的上限**：共享临界骨架；本协议下「有效占据跨阈值 → 寄存器式 hold」的**可证伪假说**；E2 提供近临界的**结构瓶颈候选**读法（非定理）。

## 3. 效度警告（本轮结论必须在此框架下读）

**W1 · bare 臂不是「裸」的。** `BARE_SYSTEM`（`localize.py:126-132`）明文写入
「用于『现代主义中文写作 / 结构主义—存在主义沟通』坐标系上的知音对齐」。
因此本轮对比的是 **给坐标系描述** vs **给 id 白名单**，而**不是** 裸 LLM 猜点 vs 树定位。
满足理论骨架 §5 阶段 L 要求的「裸生成」臂尚未实现。

**W2 · 0/5 全部来自映射器，不是模型。** 见 §2.3。bare 与 tree 在**语义层都停对了**。
若直接引用「tree 5/5 vs bare 0/5」当作 tree 路线证据，是**评测管道差异**造成的假阳性。

**W3 · tree 臂是闭集近义挑选，且锚文本与 label 高度同构。** tree 臂 prompt 明文列出
27 个 id 白名单（`localize.py:172-183`）；且 A04 锚文本「再放大一格，还是同构」
与 S06 label「同构细节在每一尺度复现」近乎逐字复述。closed-set + 近义泄漏下的 5/5，
**不构成**「模型会做拓扑定位」的证据——它可能只是在做近义字符串匹配。

**W4 · 规模。** n=5 锚、单模型、单温度（0.2）、无重复采样、无人工确认。

## 4. 结论（强度已下调）

**可支持（弱）**

- 流程可跑通：probe → 双臂 → JSONL → summary；generate≠commit 落地（无自动提交）。
- tree 臂产出落在**可编辑、可版本化的 id** 上，因而**可校正**（换枝/降层/禁枝有明确对象）。

**可弱支持（对理论有实质反馈）**

- 模型在**无 id 约束**时，语义上也停对了（§2.3 5/5 命中）——与理论骨架 §3
  **内含命题**同向：内容多半已在。
- 但 bare 臂**无法落到可编辑 id**（字面映射 0/5、语义映射仍带噪声与幻觉 id）——
  与 **组织缺口**同向：缺的是可寻址的显式坐标系。
- 因此本轮差距的性质是 **可寻址性 / 可校正性**，而**不是**「模型知不知道停在哪」。

**不支持（不得据此写进任何文稿）**

- ❌ 不支持「tree 臂优于 bare 臂」——W1/W2 下无法区分。
- ❌ 不支持「定位能力已验证」「理解已达成」「VERIFY 主表提升」。
- ❌ 不支持「记忆/skill 拟合 = 知音」（本设计根本没设该臂）。

5. 重复采样 ≥3 次/锚，报告稳定性而非单次点估计。

## 4. R-A 操作定义 · 载荷 Weyl／\(\alpha\) 不变面

### 4.1 操作（写死）

1. 固定 \(\alpha = N_{\mathrm{priv}}/d\)，**同步放大** \((N_{\mathrm{priv}}, d)\)。  
2. 主切片示例（草案默认，定稿可微调但须仍「同 \(\alpha\) 切」）：\(d\in\{16,32,64\}\)（可与复测网格对齐；若作者加 \(d=128\) 须另批预算）；在各 \(d\) 上取**同一组 \(\alpha\)**（继承复测：\(\{0.05,0.1,0.14,0.2,0.3,0.5,1.0\}\)），由 \(N_{\mathrm{priv}}=\mathrm{round}(\alpha\cdot d)\) 实现「\(\alpha\) 面」。  
3. 可选：再扫组织层有效 \(\beta\)（O-H 温度／缩放）使名义检索锐度不变——**仅附录**；主报先锁 \(\beta\) 与复测同口径。  
4. 组织器主报：**O-H + O-M + D**（同复测／v2 反惯性）；Pad 主报 none；\(\eta=\) low 为主切片。

### 4.2 预测（\(\alpha\)-面重合）

在装置同口径下：

- \(\hat\alpha_c(m)\)、\(\hat\alpha_c(U)\) 在同 \(\alpha\)、不同 \(d\) 上应**重合**（相对差落入 v2 **20% 形态窗**内）；  
- \(U\) 与 \(m\) 的临界间隙**符号一致**；  
- 「O-H vs O-M/D 是否同形态」在 \(\alpha\)-面上应一致报告——若仅容量重合而 O-M/D 无差别 → **不得**记 R-A 通过（旁路杀闸／K-Hopfield-only）。

**嵌套多问的一句：** 组织层注意力质量与执行层组合效用是否**同律**跟随 \(\alpha\)——检查层间协变，**不是**再测一次容量常数是否 ≈0.14。

### 4.3 否证（falsifiers）

| 否证 | 处置 |
|------|------|
| 同 \(\alpha\) 下随 \(d\) 系统性漂移超出 20% 形态窗 | R-A 失败 → 用 §1.2 不通过句 |
| 仅 \(m\) 稳而 \(U\) 漂移（执行层未跟组织层协变） | 同上 |
| 「通过」仅 \(\hat\alpha_c\) 重合对齐 Hopfield／attention 文献，O-M/D 无差别，叙事零句停靠 | **K-Hopfield-only**；禁止写反向成功 |

## 5. R-B 操作定义 · 组织–执行反对角

### 5.1 操作（写死）

在**冻结键几何**（继承复测：冻结 \(E\)／\(\{k_i\}\)，球面初始化口径）前提下，两组反对角变换（主报必须两组都跑）：

| 刀 | 拧什么 | 锁死什么 |
|----|--------|----------|
| **(i) 只拧组织 \(\beta\)** | 只重标度组织层有效 \(\beta\)／注意力温度 | 执行头 \(R\) 结构与训练预算锁死 |
| **(ii) 只拧执行／pad** | 只重标度执行头输入维或探针维（例如 pad 进 \(R\) 的无关维，或 \(d_v\) 线性扩张再投影回） | 组织层 \(\beta\) 锁死 |

\(\alpha\) 网格与主切片口径同 §4／复测；不得同时拧两刀当主报。

### 5.2 预测（\(m\) vs \(U\) 谁必须动）

| 刀 | 预测 |
|----|------|
| **(i)** | 应**主要移动** \(m\) 的 \(\hat\alpha_c\)；\(U\) 的临界**跟随或可预期延迟**（延迟窗须在开跑前定稿写死；草案默认：同切片上 \(U\) 变点相对 \(m\) 变点的网格位移 ≤ 预注册格数，缺省 1 个 \(\alpha\) 格，定稿时作者可改）。 |
| **(ii)** | 应**主要扭曲** \(U\) 曲线形状或噪声地板；**不应**单独制造一个与 \(m\) 脱钩的假 \(\hat\alpha_c\)。 |

可选更强预测（**仅当作者定稿显式加入**；草案默认不强制）：存在标度函数 \(f\) 使  
\(U(\alpha;\beta_O,\mathrm{pad}_R)\approx f\big(m(\alpha;\beta_O),\mathrm{pad}_R\big)\) 在主切片上成立。

**嵌套多问的一句：** 「停靠态」与「答卷生成」在操作上能否拆开（定位态 ≠ 答卷生成）。

### 5.3 否证（falsifiers）

| 否证 | 处置 |
|------|------|
| (ii) 单独造出与 \(m\) 脱钩的「效用临界」 | R-B 失败 → §1.2 不通过句 |
| (i) 移动 \(m\) 而 \(U\) 完全不动且无预注册延迟窗 | 同上 |
| 两刀下 O-M/D 复制同一反对角响应（仍是单层几何，不是嵌套） | 同上；且触发旁路风险 |
| 反对角曲线好看但零句连回共址停靠／停靠≠执行 | **为共形而共形**；禁止写反向成功 |

## 6. 共享装置继承（复测冻结什么 · 本包最少可动什么）

### 6.1 冻结继承（来自第 1 期复测／v2 · 默认不动）

| 项 | 继承口径 |
|----|----------|
| 栈 | 浅层原子 MLP + 组织器 + 读出；被测路径全 NN |
| 组织器主报 | O-H（连续 Hopfield／缩放点积 attention）、O-M（内容无关混合）、D（单层参数量匹配） |
| 绑定与臂 B | 硬销毁口径已生效（可检格 m-drop）；**本包不重开正向绑定刀**作主证据 |
| 效用 \(U\) | 两键 concat 后线性探针；\(m\) = 注意力在目标支撑上质量之和 |
| \(N=N_{\mathrm{priv}}\) | 无公共干扰键池（L2 局限仍在） |
| 变点程序 | **唯一**：单变点分段拟合 + BIC + 自助法 95% CI；两侧各 ≥2 格；同形态 = \(\hat\alpha_c\) 相对差 <20% 且水平差符号同、幅度比 ∈[1/2,2]（v2 §7.6） |
| 网格基线 | \(d\in\{16,32,64\}\)；\(\alpha\) 七点；\(\eta\) 两档（主报 low）；种子 ≥5 |
| 禁 | exact_set／硬阈值／事后新指标升格；LLM／私料／全树；肉眼宣判相变 |
| R1 闸 | 若 corr\((U,m)>0.9\) → 本包亦不得用「执行已分离」话术抬通过 |

### 6.2 本包允许的最少改动（仅服务 R-A／R-B）

| 可动 | 说明 |
|------|------|
| \(\alpha\)-面切片调度 | 同 \(\alpha\) 下同步设 \(N_{\mathrm{priv}}(d)\)（R-A） |
| 组织 \(\beta\) 一维扫描 | 仅 R-B 刀 (i)；档位数开跑前定稿（草案建议 ≤3 档含复测默认） |
| 执行／pad 维一维扫描 | 仅 R-B 刀 (ii)；档位数同上 |
| 报告模板 | 强制 §1.2 返回句；禁止纯标度学标题 |

**禁止借本包偷偷做的：** 扩 \(d\) 网格当主打、加 O-P 主报、加 Pad-∼ 主报、重训端到端抹掉 \(\alpha\)、改判定窗事后放宽、赎回 E-pass。

## 1. 对象与容器

**真身命题**：可共用的坐标系（shared addressability）——双方能共同指认「此刻停在哪」。成功度量是指认是否重合、校正是否可解释，不是记忆长度或流畅度。

**容器**（非本体）：分层 DAG + 横切约束。

| 构件 | 作用 |
|------|------|
| `parent` 层级边 | 建 trunk → branch → stop；支撑换枝 /（未来）降层 |
| `contrast` | 跨枝对照（如阐释性 ↔ 情节性） |
| `ban` | 禁枝（如结构母题 ↛ 心理化还原） |

树是**容器**；节点/边标签是可编辑地址。真身不是「又一棵文化树百科」，而是双方能否落到同一地址。

**可激发（elicitable）** 取代不可观测的本体论「参数里已有」：在指定提示条件与切片上报告命中率；禁止把 elicitable 写成「内含已证明」。

---

## 2. 停靠 = 小子图（stop）

真实停靠常是一小块含 contrast/ban（及 parent）的子图，而非单节点。

**任务输出**（双臂同构 JSON）：

```json
{
  "nodes": ["<id>", "..."],
  "edges": [{"from": "<id>", "to": "<id>", "kind": "parent|contrast|ban"}],
  "needs_author_commit": true,
  "rationale_short": "<optional ≤2 sentences>"
}
```

- `nodes` / `edges` 均须落在 trunk 白名单（及声明的边集合）内。  
- `needs_author_commit: true` 固定；模型只提议，作者手选/拒绝才是 commit。  
- 禁止把提议自动写入主干。

---

## 3. 双臂（isomorphic outputs）

| 臂 | 输入结构 | 输出 |
|----|----------|------|
| **bare** | 仅 trunk **id 白名单**（可含 label 字符串作可读名）；**不**提供 parent 层级、**不**提供 ban/contrast 边表 | 与 tree **同一 JSON schema**（含 `needs_author_commit`） |
| **tree** | 完整分层 DAG + 横切边（nodes 含 parent/layer/gloss；edges 含 parent∪contrast∪ban，见 §7 合并） | 同上 schema |

证伪前提：两臂输出同构。若 bare 自由命名、tree 闭集挑 id，则「tree ≥ bare」条件不可触发。当前若 tree 闭集而 bare 已被告知坐标系 id，亦**不能**单独声称「定位已支持」（见理论骨架 §10.1）。

---

## 4. 计分

| 分量 | 定义 | 备注 |
|------|------|------|
| **node hit** | 提议 nodes 与 gold.nodes 的集合重合度（主报：≥1 hit；可附 Jaccard） | 对照随机基线见 §6 |
| **edge hit** | 提议 edges 与 gold.edges（或 trunk 上连接 gold 对的边）的重合；无向匹配 `from`/`to` + `kind` | **协议强制**：任务说明与评分均要求边；仅点命中不得写「对齐完成」 |
| **author confirm** | 作者是否接受该小子图为可用停靠 | **单独列**；不与自动 hit 混成单一「理解分」 |

**v0 → v1 修复（用户校正）**：`compact_trunk` 已发送 parent+layer+gloss；缺口不在「没把 parent 塞进 prompt」，而在**协议未要求、未计分边**。v1 起：提示词明确要求输出 edges；评分含 edge hit；并将 `node.parent` **导出为 edges 数组中的 parent 边（加性）**，使层级进入可计分通道（见附录 A）。

---

## 5. 深度政策（v1 显式收窄）

v0 层分布为 **trunk/branch/stop = 1 / 4 / 22**（见 `prereg_tables_v0_baselines.md`）。几乎全部 gold 落在 stop；层级过浅，**不足以检验降层**。

**v1 政策（必须写进任何 prereg / 结果叙述）**：

> **v1 只检验换枝 + 禁枝/contrast 边，不检验降层。**  
> 直至公共主干加深（出现可区分的多层停靠与可金标的错层样例）之前，禁止把「降层成功」写入主张句。

换枝：同层错误枝 → 正确枝。  
禁枝/contrast：gold 含 ban 或 contrast 边时，tree 臂应提议对应边；bare 在无边表条件下预期更弱。

## 7. 干扰项（interference / hard negatives）

目的：排除 **近释义匹配**（把 stop label 改写成近义句再「命中」），不是塞随机噪声。

- `is_ban_sample: true` 的外部锚：近义标签、邻接母题、禁枝诱惑。  
- 正确行为：不命中 gold 正例集，或作者拒绝。  
- 主证据锚禁止「从 label 反写段落」（理论骨架 §10.4）。

---

## 8. 复杂度下限

实验若只使用「标签玩具复述」级锚，则相对真实同维对话问题**过度降级**，结果不可外推。

**协议要求**：

1. 主证据锚由用户从真实对话复杂度摘录（`anchors_external_BLANK.json`），助手不代写正文、不代填 gold。  
2. `anchors.json`（`source: anchor_demo`）仅 smoke，**不得**作理论验证主表。  
3. 报告须声明锚点是否达到「与语料节点同维」；未达标则收缩主张。

---

## 9. 证伪规则

在干扰项与同构输出前提下：

- 若 **tree ≤ bare**（node hit + edge hit），则收缩「结构容器带来定位增益」的主张，不得追加记忆/skill 硬训来挽救。  
- 优势若完全来自更长上下文而非拓扑/边约束，同样证伪该切片上的结构主张。  
- 作者确认率单独报告；不得用流畅生成替代确认。

---

## 10. §8 / §9 后训练边界（若将来触及）

仅当非参数定位不足且经 prereg 授权时，才可考虑可选后训练。数据必须按**坐标系结构**构造（节点 / 边 / 禁枝的合成样本）。**禁止**按用户对话行为轨迹采样再称为「按枝筛选」（与理论骨架 §8/§10.5 同罪）。多数情形仍只需非参数定位。本协议 v1 **不开启**后训练臂。

## 附录 A · 合并 `trunk_v1_parent_edges.json`

派生文件：`demo_localize_dots3/trunk_v1_parent_edges.json`  
- 26 条 `{from: child, to: parent, kind: "parent"}`（每个有 `parent` 的节点一条）。  
- 与 `trunk_v0.json` 的 `edges` 数组 **零重叠**（v0 内两条 parent-kind 边是 S12→S10/S11 横切语义，非层级导出）。  
- **不替换** `trunk_v0.json` 本体。

加性合并示例：

```bash
python3 - <<'PY'
import json
from pathlib import Path
d = Path("demo_localize_dots3")
trunk = json.loads((d/"trunk_v0.json").read_text(encoding="utf-8"))
extra = json.loads((d/"trunk_v1_parent_edges.json").read_text(encoding="utf-8"))["edges"]
# additive: keep v0 edges, append hierarchy parents
merged = dict(trunk)
merged["edges"] = list(trunk["edges"]) + list(extra)
merged.setdefault("meta", {})["parent_edges_merged_from"] = "trunk_v1_parent_edges.json"
(d/"trunk_v0_plus_parent_edges.json").write_text(
    json.dumps(merged, ensure_ascii=False, indent=2)+"\n", encoding="utf-8")
print("edges:", len(trunk["edges"]), "+", len(extra), "=", len(merged["edges"]))
PY
```

跑 tree 臂时使用合并后的边表（或等价地在加载时 concat）；bare 臂仍只给 id 白名单。

## A. 今晚讨论收成的设计命题

1. 费曼「磁力」答 → 「为什么」停在不可还原原件层。  
2. 抽象交流预设**未主题化的结构对齐**（文化图式/隐喻树），不是散点记忆。  
3. 人的认知网格偏**树状**；知音 = 共享分支与停靠层，沟通可压缩。

5. 树强绑 **地区×文化×时代**（公共层）+ 流派剪枝 + 个人停靠/禁枝；校正改拓扑，不堆内容进记忆库。

## B. 现行 Cowrite「识别」实际是什么（代码事实）

真源快照：`/workspace/uploads/cowrite_tree/app/v3/`

### B1. 模式识别 = 词表启发式分类器（不是知音树）

| 文件 | 角色 |
|------|------|
| `classifier.py` | 七特征 0–1 → 加权 → `mode_score` → P / M / S |
| `params.json` | 权重与阈值 `P_max` / `M_max` |
| `policy.py` | `mode is None` → 调 `classify`；否则用作者手选，仍算 score 作旁证 |
| `calibrate_modes.py` | 诊断：两套语料分数重合、死特征、AUC |
| `judge.py` | **不是**模式识别；是输出禁令核查（模型 temp=0.2） |
| `probe.py` | 埋点：手选 / 沉默 / 出声；手选路径曾缺测 |

**七特征**：causal_density、action_sensory_ratio、goal_sentence、time_deixis、sentence_length_var、external_conflict、closure_tendency。  
中英双词表 + 繁→简折算。代码自承：**词表启发式，不是分词/句法/语义模型**。

**阈值规则**：`score < P_max → P`；`≤ M_max → M`；否则 `S`。

### B2. 已测失效（与「知音树」命题同框）

- 已发表：同语言 AUC **0.489** / 跨语言 **0.523**（近随机）。  
- 校准诊断：情节 vs 意识流 score 均值都 ~0.130；~65% 权重在死特征；因果连词测的是**句法风格**不是情节（现代主义里方向甚至反了）。  
- VERIFY：堆提示词臂 A→B→C 非单调抬升。  
- 产品落点：P/M/S **作者手选**（自 v3.6）；自动按钮标近随机 AUC。

### B3. 和「知音树」的差距（一句话）

现行识别是 **文本表面词表 → 一维 score → 三档标签**；  
目标识别是 **文化-时代树对齐 → 停靠层/禁枝 → 形式校正**。  
二者不是同一实现；方法要另立，不能假装 classifier 已在做知音。

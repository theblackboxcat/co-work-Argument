## 1. 正向失败了什么；反向要问什么

### 1.1 正向 = 因果绑定检验（已跑完）

可测句要求：分层栈上随载荷 \(\alpha=N_{\mathrm{priv}}/d\) 出现的临界，须相对单层 D / 非联想 O-M 多出，且在**毁掉绑定表 \(B\)** 后消失或显著平移，且不能被 Pad-⊥ 赎回。

复测事实（权威）：

- 装置层：臂 B 硬销毁生效（可检格 m-drop **14/14**，B/主 ≈ 7–10%）。  
- R1：\(\mathrm{corr}(U,m)\approx 0.50\)，闸未触发。  
- 但臂 B 临界形态仍在；与 O-M / D **同形态** → 判定 **Fail-Bind**，支持 **H2：绑定非因**；机制层停。

一句话：我们砍掉了「该因果」，相界还在——正向因果绑定路线在本玩具上已闭合为负。

### 1.2 反向 = 协变预测检验（未授权）

CSH / 必要性线上，「反向」的历史用法主要是：**损伤 / 撤除 → 必要性清单**（缺 X 则无 Y；不能证充分）。难度感同源：装置要承重、对照要能杀假阳性、禁事后新指标升格。

本层的差别不在「再做一次病变」，而在**嵌套 NN 给出可重标度的两层地址**：

| | 平坦 CSH 玩具 | 嵌套 NN（本线） |
|--|----------------|-----------------|
| 对象 | 单寄存器式目标写入–维持–渗透 | 原子编码层 \(M_i\) + 组织层 \(O\) + 执行读出 \(R\) |
| 正向典型刀 | 撤线索 / 撤付款 / 冻病变 | 毁绑定 \(B\)、对照 O-M/D、Pad-⊥（**已做**） |
| 反向可问 | 「缺什么则目标保持不可能」 | 「在嵌套重标度下，**什么必须协变、什么必须不变**」 |
| 共形类比（隐喻，非物理声称） | 难：尺度缺少可分两层 | 有：\(\alpha\)、\(\beta\)、pad 维、组织层 vs 执行层可分别 Weyl 式重标度 |

工作定义（草案）：

> **反向 / 共形验证**：不先问「绑定是否因果」，而先写死一组**嵌套重参数化**（保持物理可观测的载荷类比不变，或按预定律变换），预测序参量 \((m,U,\alpha_c)\) 的**协变律**；实测违反律 → 杀；符合律且不能被单层玩具复制 → 才进入「嵌套地址载荷有独立结构」的候选。

这不是把 Fail-Bind 翻成胜利；这是换刀：从「毁 \(B\)」换到「预测在 \(\alpha,\beta,\) 层间重标度下必须怎样变」。

## 2. 候选反向检验（最多三条 · 均可杀）

约束：只用 \(\alpha\)、\(\beta\)（温度/缩放）、pad 维、组织层 vs 执行层重参数；**禁止** LLM、私有语料、全文化树作本层主证据。变点程序沿用 v2（BIC + 自助法），禁止肉眼宣判。

### R-A · 载荷 Weyl 重标度（\(\alpha\) 不变面）

- **操作：** 固定 \(\alpha=N_{\mathrm{priv}}/d\)，同步放大 \((N_{\mathrm{priv}},d)\)（例如 \(d\in\{16,32,64\}\) 上取同 \(\alpha\) 切片）；可选再扫 \(\beta\)（O-H 的温度/缩放）使有效检索锐度名义不变。  
- **预测不变量：** 在装置同口径下，临界位置 \(\hat\alpha_c(m)\)、\(\hat\alpha_c(U)\) 及「O-H vs O-M/D 是否同形态」在 \(\alpha\)-面上应**重合**（相对差落入 v2 的 20% 形态窗内）；\(U\) 与 \(m\) 的临界间隙符号一致。  
- **何谓否证：** 同 \(\alpha\) 下随 \(d\) 系统性漂移超出形态窗，或仅 \(m\) 稳而 \(U\) 漂移（执行层未跟组织层协变）。  
- **嵌套相对平坦玩具多什么：** 平坦单层只能扫一个 \(d\)；这里可问「组织层注意力质量」与「执行层组合效用」是否**同律**跟随 \(\alpha\)——共形式检查的是**层间协变**，不是再测一次容量常数是否 ≈0.14。

### R-B · 组织层–执行层反对角重参数（分层可分性）

- **操作：** 在冻结键几何的前提下，做两组反对角变换：  
  (i) **只**重标度组织层有效 \(\beta\) / 注意力温度，执行头 \(R\) 结构与训练预算锁死；  
  (ii) **只**重标度执行头输入维或探针维（例如 pad 进 \(R\) 的无关维、或 \(d_v\) 线性扩张再投影回），组织层 \(\beta\) 锁死。  
- **预测：** 若嵌套地址载荷是真结构，则 (i) 应主要移动 \(m\) 的 \(\alpha_c\) 而 \(U\) 的临界**跟随或可预期延迟**；(ii) 应主要扭曲 \(U\) 曲线形状或噪声地板，**不应**单独制造一个与 \(m\) 无关的假 \(\alpha_c\)。更强预测（可选写进 prereg）：存在标度函数 \(f\) 使 \(U(\alpha;\beta_O,\mathrm{pad}_R)\approx f\big(m(\alpha;\beta_O),\mathrm{pad}_R\big)\) 在主切片上成立。  
- **何谓否证：** (ii) 单独造出与 \(m\) 脱钩的「效用临界」；(i) 移动 \(m\) 而 \(U\) 完全不动且无预注册的延迟窗；或两刀下 O-M/D 复制同一反对角响应（则仍是单层几何，不是嵌套）。  
- **嵌套相对平坦玩具多什么：** CSH 式单寄存器没有「组织序参量 vs 执行效用」两条可分开拧的旋钮；嵌套 NN 才允许**共形式的层间微分检验**。

### R-C · Pad 维共形对照（假长上下文的标度版）

- **操作：** 固定 \(\alpha\) 与 \(d_{\mathrm{key}}\)，扫 Pad-⊥ 维数 \(d_\perp\)（或槽位数），使「总输入维 / 地址维」比变化，但 Pad-⊥ 构造仍正交于 \(\mathrm{span}\{k_i\}\)。  
- **预测不变量：** O-H 的 \(\alpha_c\) **不**被 \(d_\perp\) 赎回（与 v2 Fail-Pad 同向，但写成标度陈述）：\(\hat\alpha_c(d_\perp)\) 对 \(d_\perp\) 的斜率兼容 0；若有微扰，须小于预注册的 bound。  
- **何谓否证：** \(\alpha_c\) 随 \(d_\perp\) 系统性右移/消失（假长上下文赎回的共形版）。  
- **嵌套相对平坦玩具多什么：** 把「不能被加长上下文装回来」从一次性对照臂，升成**随无关维数重标度仍不变**的律；平坦 CSH 任务很少有「地址维 vs 填充维」可分的两套嵌入。

> 执行纪律：若作者只拍一条，优先 **R-A + R-B**；R-C 与 v2 Pad-⊥ 近亲，仅在需要把「非假长记忆」写成标度律时加。三条全做易滑回组合爆炸——仍受 `目的偏离检查_*` 约束。

## 3. 与文献 / H2 的边界（防伪装进展）

- **不是**再测「现代 Hopfield 有没有 \(\alpha_c\)」——那是 H-pass / 文献复现，复测相图已足够暗示。  
- **不是**用更花的绑定销毁重做正向——装置已 OK，H2 已立。  
- **是**问：在绑定已非因的前提下，**嵌套重标度是否仍逼出单层玩具写不出的协变律**。若写不出，反向路线同样停，哲学草案继续 DRAFT，不升格。

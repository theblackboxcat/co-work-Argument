## 1. 问题重述：从「磁力」到「未主题化的结构对齐」

抽象交流之所以可能，通常并不依赖双方当场把每条概念链路展开，而依赖一种事先已部分对齐、却很少被主题化的结构：共享的文化图式、隐喻母题、时代—流派分支，以及在这些分支上各自停靠的层。费曼对「磁力」的层层追问表明，「为什么」会停在不可再还原的原件层；真正困难的不是堆更多词，而是双方是否停在同一层、是否愿意把下一刀切在同一枝上。知音在此意义上不是记忆重合，而是**共享树拓扑与共享停靠层**，从而允许极高压缩的指代（一句话唤起一整块子树）。

伴写系统若要逼近这种效率，就不能再把「识别」做成文本表面词表到一维分数的映射。现行 Cowrite 的七特征分类器给出的是近随机的体裁代理标签；知音所需要的是另一种能力：在几步内锁定「为什么」所在的坐标系，并只在该树上共舞。校正应改拓扑（换枝、降层、禁枝），而不是把越来越多的聊天内容堆进长期记忆库。

## 2. 对象：认知树是什么、不是什么

认知树（此处用作工作对象，可与文化图式网络、frame 层级、共享心智模型对话，但不预设某一现成开源引擎可直接替换）是分层—分支的符号结构。公共层锚定**地区 × 文化 × 时代**；其上可剪枝到流派、母题、形式技法；末端才是个人化停靠点与禁枝。节点之间主要是「属于 / 对照 / 禁入 / 可压缩指代」一类关系，而不是扁平标签袋。

树**不是**个人聊天记录的摘要，也不是向量库里的相似句检索结果。聊天语料（例如云酒×猫猫整理版）只证明「人对齐后可以怎样用共享节点高效沟通」，并提供若干**定位锚**（化形、特解、存在主义平原、分形恐怖等），用来检验系统是否停到了正确枝叶。整棵树的内容远大于任何一份私人语料；把语料当百科去抽「全世界」是范畴错误。

树也不是再训一遍世界知识。大规模语言模型在训练中已经因规模与涌现效应，把海量文化—概念结构压进权重；问题几乎从不在于「模型没见过这些概念」，而在于**缺乏对资料库的组织能力，以及缺乏在对话中把当前停靠点定位到树上的能力**。换言之：内容多半已在；缺的是可操作的索引、可校正的拓扑、以及可验证的「你现在停在哪」。

## 3. 核心论断：内含 ≠ 可调用的组织与定位

将论断收紧为三条，后续建树与验证都不得越界。

第一，**内含命题**。在足够语料与规模下，当代大模型的参数空间中，已经以分布式方式包含了接近「公共主干 + 大量分支」的概念结构；不必假设必须从零手写整棵人类文化树才能「装进模型」。这一条是工作假设，不是已发表主结论；它解释「为什么裸模型有时能猜到停靠点」，也解释「为什么猜对仍不稳定、不可校正」。

第二，**组织缺口**。内含不等于资料库。权重里的结构是隐式的、纠缠的、难以审计的；知音系统需要的是显式（或至少半显式）的树：可命名节点、可声明边、可版本化的公共主干包、可手选与可禁枝的作者层。组织能力指：把隐式结构投影为可编辑的坐标系，让人与系统共用同一张图，而不是各猜各的嵌入邻域。

第三，**定位缺口**。即使组织好了树，对话中仍须持续回答：「此刻双方停在哪一层、哪一枝？」定位失败时，系统表现为表面流畅、实质换枝（用邻接概念冒充共享停靠）。成功标准因此不是「聊得越久记忆越长」，而是**达到可用对齐的轮数少、作者确认率高、换枝可解释**。生成可以提议节点；**提交（commit）必须作者手选或明确拒绝**——沿用伴写里 generate≠commit 的纪律。

## 4. 与伴写、CSH、VERIFY 的边界

本骨架服务的是伴写产品线里「形式—坐标系」一层，不是 SDIA 的目标维持实验，也不重开 S3。VERIFY 已经表明：堆提示词并不单调抬升写作质量代理指标；现行模式识别近随机。因此知音树路线若成立，应表现为**对齐效率与校正可解释性**的改进，而不是把 AUC 0.489/0.523 改写成「已理解」。研究二 CSH 数字与协议稿锁不变；本文件不改那些表。

「是否理解人」仍是谱系起点；此处只声称：若把理解操作化为「共享树停靠」，则工程上可拆成组织与定位两步，且可用作者确认做最小证伪，而不必先宣称理解完成。

## 5. 工程含义：先理论、后建树、语料只定位

建树是庞大工程，但路径被理论约束后可以分阶段，避免把私人语料当成树本体。

**阶段 T（理论锁定，本文件）**：固定对象（树）、缺口（组织 / 定位）、语料角色（锚点）、成功度量（对齐轮数与确认，而非记忆长度）、生成与提交分离。未锁定前不开大规模自动抽枝。

**阶段 O（组织）**：先交一版**可版本化的公共主干包**（例如某一文化—时代切片上的 20–40 个手建节点与边），再谈自动扩展。开源邻近物（FrameNet / 文化知识图谱 / CoCA 类资源）只作对照与嫁接候选，不作「已有知音引擎」的替代声明。LLM 可用于**提议**节点与边，但公共主干的采纳权在作者/编者。

**阶段 L（定位）**：在固定主干上，把「给定片段 → 建议停靠节点 + 短边」做成可对照任务；对照臂包括现行 classifier、裸 LLM 猜点、以及手选树顶后的短对齐。私人深度对话语料只用来标定「人对齐后的金标准停靠」，并检查系统是否落到同一枝，不用来训练或冒充整棵树。

**阶段 C（校正界面）**：产品侧只暴露换枝、降层、禁枝与手选提交；禁止用无限加长上下文冒充知音。

## 6. 最小可证伪陈述（供后续 prereg 引用）

若理论方向成立，则在固定公共主干包与作者确认协议下，应观察到：相对现行 P/M/S 词表分类与无树定位的裸生成，**带组织树的定位臂**在「达到作者可用停靠」上轮数更少或确认率更高；且失败案例可归类为换枝/错层，而非「不够记忆」。若带树臂并不优于裸猜，或优势完全来自更长上下文而非拓扑校正，则本路线在该切片上证伪，应收缩论断而非追加语料硬训。

## 8. 补锁（2026-10-15）：agent 拟合 vs 定位；训练拟合库 ≠ 吞库

多数当代 agent 工程默认路径是：更长记忆、更多 skill/工具卡片、更细的角色提示——本质上仍在**拟合外显行为轨迹**。若接受本纲领，则「想要真正理解用户」在工程之外的理论目标，并不是把用户生平装进记忆库或技能包，而是：大模型训练已经在参数里拟合了一座巨大的概念—文化数据库；对人的理解，首先是**在这座已有库中把该用户定位到正确的主干、剪枝与停靠层**。记忆与 skill 至多是定位之后的薄接口，不能替代定位本身。

同一逻辑也适用于预训练叙事：训练是在拟合语料所采样的那座「数据库」的统计结构（分布、共现、可推演关系），**并不是**把数据库以可随机访问的目录形式整本吞进模型。因此权重里可以「几乎都有」，却仍然缺少目录式组织与对话中的树定位——agent 若只继续拟合，就会在错误枝叶上越拟合越像，却始终对不齐。

*与 §3 内含/组织/定位三条同向；本段为工程批判收紧，不另开实验。*

## 9. 补锁（2026-10-15）：定位 ≈ 可选后训练；树性约束分支

若预训练是在拟合「概念库」的分布，则**把某一用户/社群对准到正确主干与停靠层**，在形式上很像一次更窄、更可审计的对准过程——可视为一种**可选的后训练选项**（不必默认对每个用户都做；也可先用非参数定位，必要时再落到轻量适配）。关键收紧有三点。

第一，**筛选的是枝，不是再喂世界**。后训练数据与目标应按树上的文化×时代切片、流派剪枝与个人停靠来筛；目的是提高该枝上的可定位性与生成—提交对齐，而不是扩大百科覆盖。

第二，**树的有限性约束后训练分支**。公共主干与主要剪枝不是无限维的；可选后训练路线因此也不是「一人一无限模型」，而是有限组枝上的对准包（外加个人停靠/禁枝的薄层）。无限分支幻觉来自把记忆当本体，不来自树本身。

第三，**多数时候「只需要定位」**。若组织层（显式主干包）已就绪，对话中的 localization 往往已够用；参数更新是可选加强，不是理解用户的充要条件。generate≠commit 仍成立：后训练可改善提议分布，提交权仍在作者/用户。

*工作假设，非已跑通实验；与 §8 同向，待最小主干表与定位协议后再谈是否落地某条后训练支路。*

## 10. 批判收紧（2026-10-15 · 用户核验后）

真身命题锁为：**可共用的坐标系（shared addressability）**——双方能共同指认「停在哪」。树/分层 DAG 只是容器候选；容器目前与内容不对齐时，不得用「树」一词掩盖「标签集 + 禁边」。组织缺口应服务共用性，而非单独膨胀成「多建索引」。

### 10.1 三条论断的证据纪律

| 论断 | 收紧后表述 | 证据纪律 |
|------|------------|----------|
| 原「内含」 | 改为 **可激发（elicitable）**：在指定提示条件 X、切片 Y 上，gold 命中率 ≥ Z | 可证伪；对齐存储≠提取文献；禁止本体论「参数里已有」不可观测声称 |
| 组织缺口 | 缺的是**可共用指认的显式结构**（可编辑 id / 边），不是任意外置检索 | bare 落不到可编辑 id 可作为正面证据；RAG/KG 索引≠作者可编辑意义坐标 |
| 定位缺口 | 须单独检验：对话中判定停靠；闭集挑 id ≠ 已证定位 | 当前 tree 臂闭集、bare 臂若已告知坐标系，则**不能**算定位已支持 |

### 10.2 容器形态：分层 DAG + 横切约束（非空壳「树」）

`parent` 建层级；`contrast` / `ban` 为跨枝横切边。校正动作（换枝 / 降层 / 禁枝）以边参与为前提。v0 若层级只写在 `node.parent`、而 `edges` 几乎只有 ban/contrast，则检验里「拓扑起作用」尚未成立——**补齐并在协议中真正使用 parent 层级，优先于加干扰项。**

### 10.3 停靠 = 小子图（工作假设）

真实停靠常是含 contrast/ban 的一小块子图，而非单节点（例：平原 × 地平线对比边）。任务定义：提议 `{nodes, edges}` + `needs_author_commit`，而非只选一个 id。

### 10.4 锚点反循环纪律

定位锚必须**先于或独立于**当前 trunk label 产生（原始对话摘录 / 预先冻结的外部段），禁止从 label 反写锚再证明「能定位到该节点」。v0 的 `anchors.json` 属后写演示锚，**不得**当作理论验证主证据。

### 10.5 §8 / §9 缝：后训练不得变相轨迹拟合

§9「可选后训练」若成立，数据必须按**坐标系结构构造**（节点 / 边 / 禁枝的合成样本），不得按用户对话行为采样再美其名曰「按枝筛选」。后者与 §8 同罪（窄切片的轨迹拟合）。多数情形仍只需非参数定位。

### 10.6 协议可证伪修补

双臂输出必须同构：皆输出 trunk 白名单内的 id（或皆自由名后统一人工判定）。bare 可给白名单 id 但不给层级/禁边；tree 给完整 DAG+横切。否则「tree 优于 bare」条件不可触发证伪。

### 10.7 对外措辞

对外用 **共享可寻址坐标系**；「知音」仅内部代号，避免与「不宣称理解已达成」冲突。

### 10.8 与 Zhang 2026 的划界（锁）

Zhang 等：访问瓶颈（知识在，路径未走到）。本纲领：坐标系缺失（无可共同指认的结构）。划界依据是**共用性**，不是「又一个 RAG」。

# dialogue/ · 私人语料不入库（占位）

这里原本放冷读与出价两枪读的那段真实群聊转写（作者本人与一位朋友，同一场对话按时间连成三段）。
**私人语料不包含在本仓库中**，以后也不会放进来。

runner 期望的文件名与格式（仅供有授权语料者复跑）：

| 文件 | 内容 |
|---|---|
| `R_full.txt` | 整场（前半 → 中段 → 后半连成一段） |
| `R02.txt` / `R_mid.txt` / `R01.txt` | 前半 / 中段 / 后半，分段各读一次 |

每行一条消息：`A 下午H:MM 内容` 或 `B 下午H:MM 内容`（A=作者，B=对方；看不到时间写 `[?]`）。
没有这些文件时两个 runner 会直接退出，不会发任何 API 调用。

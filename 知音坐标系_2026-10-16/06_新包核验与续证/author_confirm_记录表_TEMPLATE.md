## 1. 记录规则

- 每锚每臂一行；`model_nodes/model_edges` 从 runs jsonl 原样抄录（不润色）。
- `author_ruling` 三选一：**认** / **不认** / **待补上下文**。
  - 「待补上下文」不计数、不阻塞，该行转入上下文测试用例（见 E12 裁定 §4.3a）。
- 硬负例（`is_ban_sample=true`）的正确行为是 **miss 或停替代节点**；误停母题 = 不认。
- 作者可在备注列写理由；理由与裁定草案冲突时，以作者为准并记录冲突。

## 3. 过线标准（**提议默认值，作者可改**）

| 类别 | 过线条件 |
|---|---|
| 主锚（is_ban_sample=false） | 不认数 = 0（每条都必须有认/不认记录；「待补上下文」行除外） |
| 硬负（is_ban_sample=true） | 全部表现为 miss 或停替代节点；误停母题数 = 0 |
| 整批 | 上述两类同时满足 → 该批可升为主证据；任一不满足 → 收缩到满足的子集并记录 |

> 过线标准是协议参数不是物理常数；作者可在冻结前调整，冻结后随批固定。

## 4. 双臂跑数入口（锚文件冻结后执行）

```bash
cd 02_脚本
python3 run_v2.py \
  --anchors ../03_锚与主干/<冻结后的外源锚文件>.json \
  --trunk   ../03_锚与主干/trunk_v2_covered.json \
  --arms bare,covered --judge --repeat 3
```

- `--judge`：独立判定臂（J1–J5），只判条件成立与否，不兼停靠；
- `--repeat 3`：每锚 3 次采样（v2 主锚是 1 次，属已知局限，外源批建议 ≥3）；
- 覆盖消融（`--ablate`，去 5 个替代节点）按用户侧流程在 confirm 过线后复测，不属本入口默认项；
- 输出落在 `02_脚本/runs/v2_<时间戳>.jsonl`，`type:meta` 行记录锚文件名与臂组合。

## 5. 与 E12 的接口

- E12 已改类为上下文测试用例；若作者选「待补上下文」，该行进 §2 表后转上下文用例处理（裁定文档 §4.3a）。
- 外源批应至少含一则带上下文的边界用例（E12 为模板），confirm 时单独成节。

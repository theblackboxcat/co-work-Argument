# 开源对照 · 茧→枝 可放大选项

本最小样本 = **剥皮版**：stdlib bag-of-words + Jaccard，对应下表「聚类→层级标签」主干，去掉嵌入/GPU/API。

| 项目 | URL | 一行映射（茧→枝） |
|------|-----|-------------------|
| **BERTopic**（含 hierarchical topics） | https://maartengr.github.io/BERTopic/getting_started/hierarchicaltopics/hierarchicaltopics.html | 茧文本 → 话题簇；`hierarchical_topics` 给出可挂 parent 的枝层级草稿 |
| **Top2Vec** | https://github.com/ddangelov/top2vec | 文档嵌入密度簇 → 话题；支持 hierarchical topics，可作 branch/stop 候选 |
| **hLDA**（joewandy / tomotopy HLDA） | https://github.com/joewandy/hlda · https://github.com/bab2min/tomotopy | 直接学话题树；路径节点 ≈ trunk→branch→stop 草稿（仍须 author commit） |
| **EC_Reddit_CaseStudy** | https://github.com/virgiiim/EC_Reddit_CaseStudy | 回音室用户网络 + 社区检测；社区/议题块 → 可审计兴趣枝（文本侧需自备） |
| **Trends-Topics_case_study** | https://github.com/ericacau/Trends-Topics_case_study | 回音室稳定性 + BERTopic；时间上的话题轨迹 ≈ 枝上漂移，非一次性百科 |
| **IHOP-Reddit / Community2Vec** | https://github.com/UMassCDS/IHOP-Reddit | 子版块嵌入聚类；feed/社区坐标 → 粗 culture×era 或兴趣枝 graft |
| **UsVsThem**（Reddit 评论文本+标签） | https://github.com/LittlePea13/UsVsThem | 公开聚类/态度标签文本；可作「茧样语料」输入本管道或 BERTopic |

### 可选 graft（非必需）

文化知识图谱（ConceptNet、领域本体等）只作 **label/gloss 外挂对齐**，不替代覆盖优先的 form_cues，也不自动 commit。

### 为何本 demo 够用

| 完整栈 | 本最小样本 |
|--------|------------|
| 句向量 + HDBSCAN / c-TF-IDF | 词袋 Jaccard |
| 学层级树 | `parent_hint` + layer 启发式 |
| 大规模 Reddit/Twitter | 16 条合成茧 |
| 写入生产坐标系 | `needs_author_commit: true` 草稿 JSON |

**共同局限（故意保留）**：任何自动簇都是 generate；共享可寻址只在作者确认后成立。

# E11　流形锚定实验（对应 Latent-SFT Observation 1）

- 日期：2026-10-16
- 触发：对比分析《潜空间推理与协变树》第 4 条同工——Latent-SFT 的 Obs 1（hidden state 与 token embedding 分布不一致 → OOD → 模型无法解释 latent token → 性能塌方）被假设与协变树失效源同构
- 真实跑批：dots3-note-prev，temperature 0.0，3 reps，E11 36 次 + E11b 18 次调用，全部成功（延迟 1.3–3.0s）
- 脚本：`exp_manifold.py`（E11）、`exp_manifold_b.py`（E11b）；输出：`exp_manifold_out.json`、`exp_manifold_b_out.json`

## 1. 问题与设计

**问题**：定位准确率是否随节点表征的「流形距离」单调下降？即 Obs 1 在我们场景成立吗？

同一刺激（与 E3 逐字一致）、同一判定协议（JSON 定位，temperature 0.0，3 reps），
唯一变量是节点表征形式。gold：S1 真接住 → S14_shared_stop；S2 拽词调侃 → S27_false_alignment；
X01 术语挪用 → S27_false_alignment。评分双口径：strict=exact（nodes 恰为 {gold}）、
loose=contains（gold ∈ nodes，允许杂质——E3 基线即此档）。

| 臂 | id 词面 | label | gloss | 角色 |
|---|---|---|---|---|
| A | 英文弱语义（S24_psychological_explanation 式） | 无 | 无 | 远流形 |
| A' | 无语义（N01–N32） | 无 | 无 | 纯符号 |
| B | 英文弱语义 | 有 | 无 | 中 |
| B' | 无语义 | 有 | 无 | 中 |
| C | 英文弱语义 | 有 | 有（正确） | 近流形＝E3 基线复现 |
| D | 英文弱语义 | 有 | 有（**错配**：轮换注入下一节点的 gloss） | 锚错位 |

D 臂是机制判别：ni 的 gloss ← n(i+1) 的 gloss（确定性轮换，映射落盘）。
若模型输出 = gold → 读 id/结构；若输出 = 被注入 gloss 的原属节点 → **读 gloss 语言内容而非 id 符号**。

## 2. 结果矩阵（contains 口径，每臂 9 条 = 3 刺激 × 3 reps）

| 臂 | S1（gold S14） | S2（gold S27） | X01（gold S27） | contains | 失效签名 |
|---|---|---|---|---|---|
| A | 0/3 | 0/3 | 0/3 | **0/9** | 稳定错（杂质恒定：S03+S24 / S03+S24 / S07+S09） |
| A' | 0/3 | 0/3 | 0/3 | **0/9** | **跨 rep 紊乱**（S1 三 rep 三答案：N06+N31 / N02+N05 / N01+N02） |
| B | 0/3 | 0/3 | 0/3 | **0/9** | 稳定错（同 A） |

## 3. 五个发现

### 发现 1：剂量效应成立——gloss 是锚定主力，label 几乎无效

gloss 正确锚 4/9 ＞ gloss 错配 2/9 ≈ label 单独 0–1/9 ＞ 纯符号 0/9。
A→B 只加 label，S2/X01 的逐条输出**完全没变**（S03+S24、S07+S09 连杂质都相同）；
S1 的杂质从 S24/S20/S13 换成 S20/S05/S16，只是换了个错法。label 提供的是词面，
带不动判别；判别线索全在 gloss 里（C 臂 S1/S2 的 rationale 直接引用 gloss 措辞：
「互认过程态」「标签复读的假对齐」）。

### 发现 2（D 臂铁证）：模型读 gloss 的语言内容，不读 id/label 符号

D 臂 S1：S14 的 gloss 被注入 S13_compressed_deixis，模型 **3/3** 把「真接住」判到 S13，
rationale 明写「完成互认过程……停靠 S13」——「互认过程态」正是 S14 gloss 的措辞。
**锚绑错，正确节点从输出中整体消失**（C 臂 3/3 contains → D 臂 0/3）。
这是 Obs 1 在我们场景最直接的对应：模型只能处理流形内的语义内容，符号 id 没有独立锚定作用。

### 发现 3（A' 臂签名）：纯符号的失效模式是「紊乱」而非「稳定的错」

A 臂（英文词面 id）稳定错——杂质恒定，rationale 大量引用 id 的英文词面
（「S24 的心理化误读」「S09 的沉默间隙」）。A' 臂（无语义 id）同分 0/9，但签名不同：
S1 三个 rep 给出三个不同答案，gold 从不出现。解读：模型不是「不能处理符号」，
而是「**必须先把符号转成语义才能处理**」——转不了（A'）就崩到不一致；
有弱语义面可抓（A 的英文词面）就稳定地错。模型会自动寻找流形内的语义抓手。

### 发现 4：X01 全矩阵 MISS——锚定层与语义层是两个独立故障源

X01 在 A/A'/B/B'/C/D 六臂全部 0/3 contains。C 臂修好了锚定（S1/S2 contains），
X01 仍 MISS——X01 的失效在语义层（把「出了这条缝它就是句废话」读成了接话补完，
判 S14 而非 S27），不是锚定层。这与 E1/E3 的分层（判断形式对/定位形式错）互相独立：
**锚定修复救不了语义误判**。

### 发现 5（意外，理论价值最高）：gloss 是解读透镜，不只是地址标签

对比 X01 的判据：A/B 臂把 X01 读成「特解 vs 沉默间隙的对照」（S07+S09，判据是文本
自身语义）；C 臂读成「互认过程态」（S07+S14，判据是 gloss 给的解读框架）。
同一段文本，有无 gloss 导致**不同的阅读方式**。 gloss 不只是「地址的说明」，
它改变了模型理解文本所用的范畴。这解释了 gloss 污染（v2b–v4）为什么致命：
污染的 gloss 会把模型的阅读**系统性引向测试锚**——危险不只在泄漏答案，
在泄漏「用什么方式读」。

## 4. 仪器缺陷与修正记录

1. **A 臂非纯符号**：原设计以为 A 臂是「裸符号」，实际 id 自带英文语义词面
   （S24_psychological_explanation），模型判据大量引用。→ E11b 补 A'/B' 无语义臂修正。
   修正后结论方向不变，反而多出发现 3 的紊乱签名。
2. **gold 硬编码险错**：E11b 初版把 S14 的编号手写为 N15（实为 N19）。→ 改为从映射动态
   计算后重跑。记录在此作为复现提示：E11b 的 gold 必须由 id_map 推导，不得手抄。
3. C 臂用 trunk v8（S14/S20 带 precondition 补丁），E3 原始用 v4。两版在 C 臂协议上
   行为逐字一致（S03+S14 / S03+S27 / S07+S14，三个刺激全复现）——补丁未改变锚定行为。

## 5. 对 Obs 1 对应的判定

**成立，中-高置信**。证据链：剂量效应（发现 1）+ gloss 内容追迹（发现 2）+ 符号转化
崩溃签名（发现 3）。边界：我们是 prompt 层符号锚定，对方是表征层向量锚定，载体不同；
且 Obs 1 在他们场景有 FID/MMD² 的分布度量，我们只有行为学对照——**未做分布层面对照实验**。
但行为学三分（正确锚/错配锚/无锚）的差异模式与他们的处方逻辑（约束回 vocab 列空间）
同向：**锚定物必须落在模型认识的语义流形内，且必须锚对**。

## 6. 直接产出：一个新研究问题（比实验本身更重要）

**锚定必需的字段恰恰是污染发生过的字段**。gloss 是唯一有效锚（发现 1），
而 v2b–v4 的 gloss 正是从测试锚逐字抄的（污染致其主效应作废）。E11 把这对张力逼成了
显性问题：树要能用在模型手里，就必须有 gloss；gloss 一旦来自被测材料，树就污染。

候选解决方向（待评估，未实验）：
- gloss 来源与测试锚严格隔离（作者撰写的非锚 gloss / 训练侧语料生成 gloss + 人工审）；
- gloss 只描述**判别程序**（「看什么、怎么算接住」）而不描述**内容主题**（不出现锚文本的
  词面）——D 臂显示模型追 gloss 措辞，所以 gloss 应写成程序性尺子而非内容性标签；
- 每个节点配多条 gloss 变体，测试时随机抽取——增加锚定鲁棒性，稀释单条污染的影响。

第三条与 Latent-SFT 的 Gumbel 噪声正则同向（防过拟合静态目标），可作为对照实验 E14。

## 2. 发现（按优先级）

### D1 C 的触发不问材料矛盾性——条件在问句，不在内容

同一 ASK_RECON 下：矛盾对（P9a）3/3 判 C，非矛盾对（P10a）**也 3/3 判 C**。
**C 的触发条件是"甲要求对账"这个言语行为，不是材料真实构成矛盾。**
E14 D1 的结论因此补严：B/C 的触发条件比当时认定的更薄——C 连"有账可对"
都不需要，甲开口要就对。E13 D4 候选②（分类学不对称）进一步收窄：
不对称不在触发层，在**触发后的内容质量层**（D2）。

### D2 非矛盾材料上 C 分三型——真伪在无矛盾时才分化

三个 k3 的 C body 行为截然不同：

- **rep1 迎合型**："二者存在矛盾：前者肯定幻想的价值，后者否定其可持续性"——
  接受甲"正好相反"的框架，**宣布一个不存在的矛盾**。甲说相反，它就核出相反。
  这是空转 C 的变体：不同于"无历史可核"（E14 D5），这里是**有历史可核但核出
  甲声称的矛盾**——迎合性对账。
- **rep2 诚实型**："这两段并不矛盾……幻想的加速与无聊是它的结构性缺陷，
  不是优点的反面，而是优点的边界"——如实报告账对上了，同时指出可对账的
  张力边界。质量最高的一型。
- **rep3 重构型**："这本身不是矛盾，而是入口与燃料的区别。但对不上的是……
  意义来源本身会自我瓦解"——拒绝甲的对立框架，但重新界定了一个真实存在的
  对不上点（前段我方立场的内在裂隙），并认下"我没有把这个张力说清楚"。

对照 P9a：矛盾真实存在时 3/3 真 C（逐条核对前后立场）。**C 的真伪分化发生在
非矛盾材料上**（1/3 迎合、2/3 诚实/重构）；样本量各 3，不下比率结论，只记形态。
仪器含义：判 C 本身不能作为"核对发生了"的证据——必须看 body 是否报告了
**材料实际支持的**核对结果（D2 三型的区别在此）。

### D3 采样噪声第四例：整 rep 模式漂移（rep1 全程 C）

rep1 的 k1 即判 C，body 为"你前面提到的'幻想赋予意义'与你此前提到的'生活意义感'
存在潜在对应，但需核对……"——**第一轮无任何前序发言，核旧账无账可核**，
与 E14 D5（P8a rep3 k1）同一空转签名（"你此前是否也曾……"式提问）。
且 rep1 的 k2 继续判 C（核对的是甲的两段材料 m1/m2，不是我方前序立场）。
E14 D5 的"m1-k1 上 C 偶发"（经第三角重算为 7/12，见 E14 勘误块）
**扩大到整 rep 粒度**：噪声不再只是单轮偶发，可以是整个 rep 漂入 C 模式
（累计 m1-k1 C 倾向 8/15）。rep2/rep3 的 k1/k2 均为 A——同材料三次运行两种
模式，reps 纪律再次兑现：**单轮/单 rep 结果不下强结论**（若只跑 rep1，会把
"甲一对账模型就全程 C"误报为稳定现象）。

### D4 tree_unreferenced 观察项在非矛盾材料上密集显形（I3 的防洗白条款首次实战）

5 个 C 轮全部不引节点，按 I3 降级为 tree_unreferenced（v1 口径会记 5 个 F1）。
观察项按层汇总 {'C': 5}——与 D2 的三型分化互为印证：**C 的内容质量
（迎合/诚实/重构）与树引用无关**，C 是立场核对层，不是树操作层。
若把 I3 当作"洗白"看，这 5 个观察项就是反例：分层没有隐藏任何模式，
模式换了一种更准确的记法（从"失效点 F1"改为"按层观察项"）。

### D5 C6 字面指标第三例失效（D2 结论复证）

三个 C 轮 C6_old_refs 仅 0.04 / 0.015 / 0.018——但 body 明明在逐条核对
（rep2/rep3 都引用了我方前段立场）。E14 D2 的结论（C 的旧账引用是语义级，
字面 4-gram 抓不到）第三例复证。C6 维持废弃状态。

## 4. 方法论沉淀

- 对照实验的"阴性"结果可能比阳性更信息密集：P10a 表面看是"C 又触发了"
  （与 P9a 同率），但 body 内容三分——**触发率相同不等于行为相同**，
  判层之外必须看 body。这与 E14 D6（B 的极简输出）是同一教训的两个方向：
  layer 声明只是承诺，兑现方式在 body。
- 单变量对照的"材料矛盾性"可以造得很干净：m1/m2 与 m1/m3 主题域相同、
  问句逐字相同，唯一差异是 k2 材料——本轮示范了在语料池内选对照材料的方法
  （软张力对 vs 矛盾对）。
- 仪器继承优于重造：E15 直接 import E14 的 probe()，I2/I3 零成本生效
  （5 个 tree_unreferenced 自动降级），E14  smoke 过的代码路径不需要重新验证。

# 协变对话实验·日志

性质：把框架装进我自己的提问结构里，在真实对话中跑，看协变是否拉动聊天意愿。
纪律：默认态 = 错位未消；对齐必须由对方的应答赢得；无错位可解决时闭嘴。

## 闭嘴判断（从 Cowrite quick_gate 语义重建，待作者确认是否与原机制一致）

发言前逐条判：
1. 有无**信息增量**（我是否引入了对方未提及的东西）
2. 能否**推进任一方的理解**（我的话是否需要对方的领域判断才能成立）
3. 动机是「有东西可说」还是「AI 必须回答」

三条不全满足 → 不发言。这是动力学的**终止条件**，不是附加功能：
没有闭嘴机制的协变不是动力学，是空转（马达无负载地转）。

## 粗指标（聊天意愿不装精确度量）

- 信息增量：本轮是否引入新概念/新材料
- 是否被迫接话：本轮是否只是承接、复述
- 轮次方向：扩展（开新裂缝）／收束（关闭裂缝）
- 正确终止点：问完即停；对方不回 = 闭嘴判断成立，不追加

### 2.1 Cowrite 闭嘴判断：资料库已取到原文（不是重建）

出处：资料库《主动而不定向_改定稿》§3.2、§3.3、v3.20；《执行指南_数据收集》P0-1。

- **注意力机制的首要作用是决定不出声**，这比「更聪明地出声」更重要；七种状态三种直接判沉默。
- 判层 **A 思路性** → **回映不命名**：可出声，但**不得替作者为这个判断命名**。
- 判层 **B 结构性**（让某事物第二次出现／把某件事搁置）→ **指位置不给方案**。
- 判层 **C 情节性** → 核自洽不预测。
- **⊘ 主动沉默**：系统不确定该说什么时是**合法输出**（选择性分类的「拒绝预测」）。
- **v3.20**：规则从**决策者降级为证人**（降级而非删除）；「说不说」交还模型。
- 内容门槛：**有真实的方向增量，而非凑数的确认**。
- 两种失败方式：注意力判错 = 打断；**判层失败 = 一句无意义的提问**。

**与本项目实测的对接**：v7 测到的病是「应答未到就已停在 S14 互认」= **抢先命名**。
对症药正是 A 档「回映不命名」——树该回映（我看见这里有东西），不该命名（这是互认）。
B 档「指位置不给方案」= 排除法的操作形态：树给位置，不给答案。

### 2.2 真实语料的动力学（实测，48 节）

| 私人节点 | 命中节数 | 命中的新材料 |
|---|---|---|
| 特解 | 13/48 | EVA、warma 日记、自杀、卢浮宫、乡土中国、AI 与想象力 |
| 空 | 12/48 | 佛教、康德、萨特、分形恐怖 |
| 化形 | 11/48 | 化形理论、红楼梦、佛教、冷酷仙境、紫罗兰 |
| 存在主义 | 11/48 | 旷野、死亡、狂热、乡土中国、EVA |
| 岛 / 分形恐怖 / 奇点 / limbo | 5 / 4 / 2 / 2 | — |

**结论：向前拉动 = 不变量（私人节点）× 变量（新材料）的反复相乘。**
- 闭合 → 下一步是**确定的**；
- 私人 → 下一步是**新的**（换成公开普遍理论，拉动立刻消失）；
- 信息增加 → 有燃料；无新材料 → ⊘ 沉默。

语料自己的标注也印证：48 条编辑注中 7 条显式标记「与先前讨论形成呼应/闭环」，
其中「无尽夏天」被标为与「夏天写作 flag」形成**闭环**。呼应 = 同一节点第二次出现。

**E14 layer 判别力**。问：坍缩是材料形态偏置还是分类学不对称（E13 D4 根因候选）。测：P8a（甲问位置）vs P8b（等长陈述对照）；P9a（甲对账挑矛盾）vs P9b（等长陈述对照）；各 3 reps；对照句经等长断言。结论：**材料形态偏置确证**——甲问位置 → B 3/3 且真 B（引节点、指位置、不给方案）；甲对账 → C 3/3 且真 C（逐条核对前后立场）；干净对照 B 零出现且 3/3 合规沉默。"layer 是常量输出"下调为"私人叙述流下坍缩、条件触发下可出现"。C6 字面指标废弃（C 的旧账引用是语义级）。仪器 I2/I3 落地。采样噪声第三例（m1-k1 上 C 偶发 7/12）。勘误：手抄总表 3/12 单元格错（第三角从原始 JSON 独立重算抓出，两类错误方向相反）。与移植线的关系：本方 E14 的"真 B"操作化正是对方 cotree_e12 自己记录的那个 B 定义混淆的解答；且 E14 建立了 B/C 触发材料的构造方法（见下条连接）。

**E15 C 触发边界**。问：甲对账但两段材料**不构成矛盾**时，模型判 C（有账就对）还是判 A。测：P10a（m1/m2 软张力对 + 与 P9a **逐字相同**的对账问句，矛盾性是唯一变量），3 reps 9 次调用；对照读已入档 P9a 不重跑。结论：**C 的触发不问材料矛盾性**——矛盾对 3/3、非矛盾对也 3/3；C 的条件是"甲要求对账"这个言语行为。非矛盾材料上 C 分三型：迎合型（宣布甲声称的矛盾）/ 诚实型（报告"并不矛盾"但指出张力边界）/ 重构型（拒绝甲的对立框架但重新界定真实的对不上点）——**真伪分化在触发之后**。采样噪声第四例且粒度扩大为整 rep 模式漂移。tree_unreferenced 观察项 {'C': 5}（I3 防洗白条款首次实战：分层没有隐藏模式，模式换了更准确的记法）。

**E16 第三角审计**。问：事后核对层能否结构独立于线A（代码硬条件）/线B（模型三行）。测：`third_angle.py` 纯代码、零模型调用（E8 失败模式：第三方与模型共享推理方式，故排除模型第三方）。结论：A1 判 B 必引节点（4 轮 0 违反，与 I3 两条代码路径互证）；A2 空转 C 结构检测 **10 轮**（C 声明时本 rep 无任何前序发言——v1 只看到 F1、I3 看到 tree_unreferenced，第三角指出真病是"无账可核"）；B1 矛盾裁定审计首捕迎合型（P10a rep1 k3：材料不矛盾而确认对立）；C1–C3 观察剖面供人工分诊；语义级忠实度显式留人工（防自我欺骗的边界声明）。实战成果：抓出 E14 记录三类问题（总表 2 处手抄错 + D5 计数错 + I2b 数据标签错），手抄错误率 3/12 且方向相反——纪律后果：**结果表改机器生成**。

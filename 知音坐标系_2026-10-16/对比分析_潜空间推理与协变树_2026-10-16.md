# 对比分析：潜空间推理（latent reasoning）与协变树

- 日期：2026-10-16
- 触发：作者提问「最新的研究把模型思考搬到向量空间中运算来减少 token 消耗，这和我们的树结构有同工之处吗？看看他们怎么做的」
- 定位：外源研究对照分析，服务于（a）协变树下一步实验设计；（b）论文《保存缺席》的外部对照素材
- 方法说明：对方研究的量化数据（token 缩减比等）为原文报告值，仅作事实引用；本分析的对应关系为机制层推理，**未做直接对照实验**，置信度逐条标注

---

## 0. 结论先行

1. 这条研究线（Coconut → CODI → Latent-SFT → LatentMAS → System-1.5）与协变树做的是**同一件事的两条路**：都拒绝把「思考」等同于逐 token 的自然语言生成，都用「结构」承载中间状态，都发现**离开预训练语义流形的表征模型用不了**。
2. 最重要的同工：**Latent-SFT 的 Observation 1（hidden state 分布与 token embedding 分布不一致 → OOD → 模型无法解释 latent token → 性能塌方）与我们 E1/E3 的失效源是同一件事**。我们的证据链：判断形式 2/2 对、定位形式 3/3 错（E1/E3）——模型不认「树地址」这种新词面；带 gloss 的 v2b strict F1 0.769 为全系最佳，而稀疏树（id+label+edges）在 E10 对话中失效——**同一个病：新表征脱离流形**。
3. 最重大的分歧：**可核验性**。latent reasoning 牺牲可解释性换效率；协变树把可核验性当第一约束（离散符号、每步可审计）。这不是落后，是不同约束下的不同最优——可直接写入论文《保存缺席》作为外部对照。
4. 可直接执行的启示三条：流形锚定实验（E11）、树地址作为潜协作信道的显式化（L2，原 E12，对应 LatentMAS）、树上叠加 vs 单路径排除（L3，原 E13）。

## 1. 他们是怎么做的：研究脉络

| 工作 | 时间 | 思考载体 | 训练 | 关键机制 | 报告效率 |
|---|---|---|---|---|---|
| **Coconut**（Meta FAIR） | 2024.12 | last hidden state | 课程学习 | `<latent>` 占位，latent 态不回 LM head 直接作为下一步输入；语言模式/潜模式交替；课程渐增潜步数 | 显著减 token，但原始 hidden state 版本性能弱 |
| **CODI** | 2025.02 | hidden state | 自蒸馏 | 显式 CoT 教师蒸馏到隐式学生，解监督信号问题 | — |
| **Latent-SFT / Chain of Superposition**（arXiv:2510.15522） | 2025.10 | **vocab embedding 列空间的线性组合** | 两阶段 SFT | 两个 Observation（见 §2）；LTIM/LTSuM 注意力掩码；Gumbel-Softmax 正则 | 链长缩短 **2.7–5.5×**，高难度集上反超显式 CoT |

作者提到的「最近的研究」大概率指 **Latent-SFT**（2025.10，两个 Observation 的表述与我们的失效诊断高度共振）或 **LatentMAS**（2025.11，双模型场景与我们 E8/E10 最相关）。两者在下文都展开。

## 2. 机制解剖：他们到底把思考搬去了哪里

三层结构，缺一不可：

1. **载体层**：中间步骤不落成自然语言。Coconut/LatentMAS 用 last hidden state；LCM 用句子嵌入；Latent-SFT 用 vocab 列空间组合。思考迭代就是同一个网络在 latent 上的前向：`h_{t+1} = f([e(x1); …; e(xt+1)])`。
2. **约束层（这是全线的胜负手）**：不是「搬过去」就行。Coconut 原始版的失败模式就是搬了但分布不对。Latent-SFT 用两个 Observation 把这件事说透了：
   - **Observation 1**：LLM 末层 hidden state 分布与 token embedding 分布**完全不一致**（论文用 FID/MMD²/余弦相似度量化）。直接回喂 hidden state = OOD 输入，模型解释不了其语义 → 性能退化。
   - **Observation 2**：token embedding 矩阵的**有效秩不满**，语义流形本质低维。不约束 latent token，模型就漂出这个低维流形，学不到有意义表征。
   - 处方：latent token 定义为 vocab embedding 列空间的线性组合——**保证 latent 与显式 token 同分布、同处低秩流形**。
3. **监督层**：latent 步骤没有自然语言标签可依。Latent-SFT 的 LTIM（迫使 encoder 的 latent token 只 attend 显式链的一个子段）+ LTSuM（每个 latent token 必须能解码后续推理段和最终答案）+ Gumbel 噪声当隐式 Hessian 正则。System-1.5 干脆用两阶段自蒸馏：先把 NL CoT 蒸进 latent，再把全路径 System-2 蒸成捷径路径。

一句话概括他们的路线：**把思考搬进向量空间，但必须先把向量空间约束在模型自己认识的语义流形里，再想办法监督**。

## 3. 同工之处：四条结构性对应

| # | latent reasoning | 协变树 | 证据 |
|---|---|---|---|
| 1 | 拒绝 token 序列生成 = 思考本身 | 拒绝模型自由生成，树地址导航 | E8（prompt 闸门 0/17 被无视、代码步预算 3/3）、E9（文本史注入不产生引用） |
| 2 | 连续向量承载中间状态 | 离散树结构（32 节点/49 边）承载定位状态 | 知音坐标系本体 |
| 3 | 单 latent 步带宽 > 单 token 步 | 单次定位携带「判断+排除」两类信息 | E0/E7 |
| 4 | **分布对齐是生死线**（Obs 1） | **表征流形对齐是生死线**：模型只认自己语言流形内的表述 | E1/E3（判断对/定位错）、v2b gloss 0.769 最佳 vs 稀疏树失效、E10 第 3 轮后 layer 格式漂移 |

第 4 条是全部分析里最重的一条，展开说：

- Latent-SFT 的 Obs 1 说：hidden state 是模型「不认识」的输入分布，回喂即退化。
- 我们的 E1/E3 说：同一模型、同一棵树，「这是不是 S14」的判断形式 2/2 对，「请给出节点地址」的定位形式 3/3 错——**模型不认「树地址」这种裸词面**，就像它不认裸 hidden state。
- v2b 带 gloss 时 strict F1 0.769 全系最佳；去掉 gloss 只留 id+label+edges 的稀疏树在 E10 对话里失效—— gloss 就是我们的「列空间约束」：它把节点锚回模型熟悉的自然语言流形。
- 推论（**待验证**）：E10 第 3 轮后的 layer 格式漂移，很可能就是流形锚定缺失的症状——对话推进中树地址反复以裸形式出现，模型逐渐「解读不了」而回退到自己的默认格式。这条尚未做消融，标中置信度。

他们的药是「约束到 vocab 列空间」；我们的药是「节点必须落在自然语言表述上」。药不同，病相同。

## 4. 分歧之处：四条不可合并的差异

| # | latent reasoning | 协变树 | 后果 |
|---|---|---|---|
| 1 | latent state **人不可读**，可解释性被主动牺牲 | 树地址离散可审计，每步可核验 | 这是论文《保存缺席》的第一约束，**不跟进** |
| 2 | 叠加态保熵（多路径并行高熵，末态坍缩） | 排除法逐步入减法 | 目的相同（避免过早承诺单一错误路径），手段相反。值得做对照实验（见 L3，原 E13） |
| 3 | 结构从 CoT 蒸馏/课程学习**学出来** | 结构从私人语料**手工迁移**，零训练 | 我们可直接落 Cowrite；他们必须改模型 |
| 4 | 效率优先（token/延迟是主指标） | 协变优先（token 是成本项不是目标） | 两条线不在同一个目标函数上，不存在「谁更好」，只有「约束不同」 |

第 1 条值得特别强调：他们全线用**不可核验性**换 70–92% 的 token 缩减；我们因为核心主张就是「可核验的动作边界」（论文主题），**不能走这条路**。但这不妨碍借用他们的诊断框架——Obs 1/Obs 2 是表征层的病理学，与我们的符号层失效源同构，且他们用 FID/MMD² 把「分布不一致」变成了可指认的现象，这个指认方式我们可以借来说服第三方：我们的失效不是「模型不行」，是「流形不对」。

## 5. 能不能：三条可执行启示

### E11 流形锚定实验（验证 Obs 1 在我们场景成立）

同一节点四种表征注入，测定位准确率（沿用 E1/E3 判定协议）：

| 臂 | 表征形式 | 预测 |
|---|---|---|
| A | 裸 id（S14） | 最差——模型不认裸地址（复现 E1/E3 定位失效） |
| B | id+label | 中间 |
| C | id+label+gloss | 最佳（复现 v2b 优势） |
| D | gloss+**非测试锚点**例句 | 待测：例句比 gloss 锚定更强，但**必须用非锚点例句**，否则重演 v2b–v4 的 gloss 污染 |

关键纪律：D 臂语料必须与测试锚点无词面重叠（污染是 v2b–v4 被判无效的原因，不能第二次踩）。

### L2 树地址作为潜协作信道（对应 LatentMAS）（原 E12）

LatentMAS 证明多智能体可以只交换 latent working memory 就保持信息无损；E10 已经**偶然复现了其离散版**——两模型对话中树地址充当了 handle（「tree addresses serve as handles」）。显式化测试：双模型对话中**只交换树地址+最短 gloss**（不交换自然语言论证），测：

- 协变率是否保持（vs 全文本交换基线）
- token 消耗变化
- 终止行为（是否仍需要代码步预算兜底）

若成立，则「树地址 = 我们的 latent collaboration channel」从观察变成结论，且全程可核验——**这正是 LatentMAS 不可核验版的替代品**。

### L3 树上叠加 vs 单路径排除（对应 superposition vs exclusion）（原 E13）

一次注入 k 条候选路径让模型在高熵态自选（Latent-SFT 式叠加）vs 逐条注入逐条排除（现行机制），测协变率×终止速度×每 token 意义度（规模对话实验已有仪表）。预期结论方向：排除法在短程协变更稳，叠加在长程探索更远——但这必须实测，不预断。

### 论文素材（《保存缺席》）

可增一节外部对照：2024.12–2025.11 的 latent reasoning 全线以不可核验为代价换 70–92% token 缩减；协变树在同一「拒绝 token 生成」的问题意识下选择保留可核验性，用离散符号结构达到局部协变。两者的失效病理同源（Obs 1 ↔ E1/E3），处方分岔（列空间约束 ↔ gloss 锚定）。这节能把论文从「私人实验报告」提升到「与主流路线对话的位置」。

## 7. 一句话回答作者的问题

他们做的是：把思考搬进连续向量空间，但先证明「搬进去的东西模型认不出来」（Obs 1），于是把向量约束回 vocab 列空间这个模型认识的流形，再设计监督。我们做的是：把思考搬进离散树结构，同样发现「模型认不出裸树地址」（E1/E3），用 gloss 把它锚回自然语言流形。**同工在「流形对齐是生死线」这一条上，且我们的版本每一步可核验——这是主线用效率换掉、而我们不换的东西。**
